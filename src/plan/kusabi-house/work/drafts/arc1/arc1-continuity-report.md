## 2. ผลตรวจรายหมวด

### 2.1 ตารางเวลา/อากาศ

- **โครงวัน**: Arc = ศุกร์เย็นมาถึง → เสาร์ข่าวลือ → อาทิตย์ของหาย+ขึ้นเขา → จันทร์เช้ากลับ ตรงคำตัดสิน bible 2.2 ("ยึดฝั่ง chapter_outlines ขยาย 3 วันเต็ม") — บท 2 เปิด "เช้าวันเสาร์" (ch2:3), บท 3 ยืนยันเป็นอาทิตย์ผ่าน "วันนี้เป็นวันสุดท้าย พรุ่งนี้เช้ารถออกเก้าโมง" (ch3:617) และรถบัสเที่ยวสุดท้าย "หกโมงเย็นวันจันทร์" (ch2:935) — สอดคล้องกันเองและกับ timeline.md ที่คณะกรรมการถือ Arc 1 = 3 คืน
- **อากาศรายวันเทียบ bible 7.1**: ศุกร์ ฝนปรอยตอนลงรถ (ch1:5-9) → เบาลงตอนถึง (ch1:159) → เลิกก่อนจบมื้อค่ำ (ch1:777) → คืนเงียบผิดปกติ (ch1:985-1085) ✅ / เสาร์ เมฆเคลือบ+แดดคาบเกี่ยว (ch2:15, 521-523) → หมอกลง 4 โมงเย็น (ch2:547-549) → คืนฟ้าโปรง (ch2:673) ✅ / อาทิตย์ เมฆต่ำครึ้มเย็นกว่าเมื่อวาน (ch3:59, 549) → ฝนมาระหว่างทางขึ้น (ch3:1171) → ฝนหนักท้ายบท 4 (ch4:1293) ✅ — ไล่ระดับตาม bible หมวด 3 (ปรอย→เมฆ→หมอก→ฝนกลางทาง→ฝนหนัก) ครบ
- **นาฬิกาภายในบท 3-4**: ออกเดิน 14:30 (ch3:763) → พ้นหมู่บ้าน 14:45 (ch3:901) → ศาลเจ้า 15:30 (ch3:1075) → เห็นบ้าน ~16:00 (ch3:1237) → หน้าประตู 16:10 (ch3:1289) → สำรวจ 20 นาที + รอบ 10 นาทีสามรอบ → 17:45 (ch4:495) → กำหนดออกก่อน 17:55 (ch4:503) → ประตูปิด — ตรงหมุด bible 7.4 (ถึงบ้านใกล้ 4 โมง, ประตูปิด ~5 โมงครึ่ง-6 โมง, ยังมีแสงไม่มืดสนิท — ch4:983-985 ยังเห็นแสงม่วงจาง) ✅
- **ตรวจพบและแก้**: เวลาอาหารเช้าวันเสาร์ขัดกับแผนมิซากิ (ดูหมวด 3 จุดที่ 1) — หลังแก้เป็น 08:30 เวลาถัดไปทั้งวันยังไหลลื่น (ออกเดิน "ตอนเก้าโมงเช้า" ch2:135, ออกจากร้าน "สิบโมงแล้ว" ch2:301, ถึงพิพิธภัณฑ์นัด 10:00 ตรงเวลา ch2:309)

### 2.2 ของชิ้นสำคัญ

- **ผ้าพันคอริสะ** — ตรงตาราง bible 7.2 ทุกจุด: ปลูกที่มาคืนแรก "มิซาจังเลือกให้ตอนวันเกิดฉันปีที่แล้ว" (ch1:785) → ใส่ตอนเดินเล่นบ่ายแก่เสาร์ (ch2:555) → พับบนตะเกียบแล้วหายเช้าอาทิตย์ (ch3:77-141) → พบแขวนรั้วบ้านหลังใน เปียก มีคาบโคลนที่ดินแถวนั้นไม่มี (ch3:453-505) → ซัก ตาก (ch3:845-869) → คล้องคอตอนขึ้นเขา "ยังชื้นเล็กน้อยที่ปลาย" (ch3:903) → ในบ้านเปียกฝนหนักขึ้นเรื่อย ๆ (ch4:71 → 913 → 1009 "หนักไปด้วยน้ำฝน") ✅ — เส้นสถานะความชื้นไล่ระดับสมเหตุผลตลอด
- **กล้อง/คลิปนาโอะ** — คลิปแรกในรถ "ทางบ้านทั้งสิบเจ็ด" (ch1:21-29) → พิพิธภัณฑ์ (ch2:341) → "แชนเนล ep.1" หน้าทางขึ้น (ch3:917) → ในบ้านหยุดถ่ายเองตรงรอยเลือดกลางประโยค (ch4:213-219) ✅ ตรง bible หมวด 3 และ 7.2 — และยังไม่มีใครเคยดูคลิปย้อนหลังตามหมุด 7.4 ✅
- **แผนที่อากิระ** — ปลูกแบบเล่า+กางให้ดูแวบเดียวคืนเสาร์ (ch2:879-885) → ของจริงพับสี่ทบตอนวางแผน (ch3:777-779) → ใช้เทียบเส้นทาง (ch3:783-813) → หยิบออกมาตอนติดบ้าน พบว่าไม่มีผังบ้าน (ch4:895-905) ✅ (แก้ที่เก็บจากกระเป๋ากางเกง → ซองเอกสาร หมวด 3 จุดที่ 5)
- **มือถือ** — ใช้ได้แถวเรียวกัง (ch1:887-893) → สัญญาณลดทีละเครื่องระหว่างทาง 15:05-15:25 (ch3:1001-1031) → "ทั้งห้าเครื่อง...ตั้งแต่กลางทาง" (ch4:33, 881-885) ✅ ตรง bible 7.2 — จับเวลาบนมือถือมิซากิ (ch4:293, 951) ไม่ขัดกับการไม่มีสัญญาณ
- **เทปม้วนแรก** — บท 4 ห้องนั่งเล่น: เสียงผู้หญิงพูดธรรมดา → เสียงเคาะสม่ำเสมอ → ไคโตะกดปิด "พอ" (ch4:627-697) ✅ ตรง bible หมวด 3 ไอเดีย 4 — ไม่มีชื่ออายาเมะ/อ้าง prologue เกินเส้นห้าม 6.2/6.3 ✅

### 2.3 ใครรู้อะไรตอนไหน (เทียบ bible 7.3 ทุกจุดปิดบท)

- **จบบท 1**: ทุกคนรู้ชื่อบ้านคุซาบิ+เรื่องเล่า (ch1:489-523) / ริสะมองชิองแบบ "ดูใครบางคน" (ch1:739-745) / เรียวยะคนเดียวได้ยินเสียงผู้หญิง (ch1:1043-1069) + จดกลิ่นน้ำยาฆ่าเชื้อ (ch1:713-719) ✅
- **จบบท 2**: 5 เวอร์ชันข่าวลือ (อันดับ 5→1 นับได้ครบ ch2:693-777 + โบนัสอากิระ) / เงาชุดขาว: ริสะเห็น→กระซิบมิซากิ→มิซากิรู้แค่ "ริสะเห็นอะไร" (ch2:607-643) — เรียวยะเห็นริสะหยุดจ้องแต่สรุปเองว่า "คงแค่ดูหมอก" (ch2:1045-1051), ไคโตะ/นาโอะไม่รู้ ✅ ตรงหมุด 7.4 ที่สุด (นับคนรู้เรื่องเงา = 2) / เรียวยะจับ "ชิองรู้ทางละเอียดเกินสองปีครึ่ง" (ch2:409-417) + "เสียงไม่ต่อเนื่อง" (ch2:1017-1037) ✅
- **จบบท 3**: ทุกคนรู้ของถูกย้าย+ป้ายถูกขูด+ไม่มีสัญญาณ / เรียวยะพูดจังหวะการหายให้กลุ่มฟังระดับหนึ่งแล้วไม่ดันต่อ (ch3:531-537, 657-667) / ริสะรู้สึกผิด (ch3:639-645) ✅
- **จบบท 4**: ทุกคนสรุป "มีคนล็อก = ไม่ใช่ผี" (ch4:925-935) / เรียวยะเห็นรอยรองเท้าทำงานบนฝุ่นแต่ไม่เชื่อมกับรองเท้าที่เรียวกัง (ch4:749-767 — รอยนั้น "แห้งเกรียบ" กับของกลุ่ม "ยังชื้น" แยกชัด) / ประโยคริสะเรื่องหน้าต่างชั้นสองถูกประตูปิดกลืน (ch4:799-803, 1013) ✅
- **เส้นห้าม 6.1 (ห้าม POV/เฉลยชิอง)**: ตรวจครบ 4 บท — ไม่มี POV ชิอง ไม่มีความคิดเขา ความผิดปกติที่แสดงเป็นแค่จำชื่อเก่ง / รู้ทางละเอียด / เงียบตอนพูดถึงข่าวลือ (ch2:809-815) / จำผ้าริสะได้ (ch3:261) — ไม่มีประโยคลายเซ็นต้องห้ามตาม 6.2 (มีแค่ "ชื่อเป็นสิ่งที่ควรเรียกให้ถูกครับ" ch1:665 ซึ่ง bible อนุมัติไว้ในไอเดีย 1.3) ✅
- **ความรู้ของริสะเรื่อง "ไม่เคยไปทางขึ้นเขา"** (ch3:417) ไม่ขัดกับเหตุการณ์เงาชุดขาว (เกิดที่ทุ่งหลังบ้าน ไม่ใช่ทางขึ้น ch2:585-643) ✅

### 2.4 การเรียกชื่อ (เทียบตาราง bible 1.1 รายคู่)

- นาโอะ→เรียวยะ "มึง/กู" ตลอด; คำว่า "เรียวยะจัง" ปรากฏครั้งเดียว ch2:93 ในฐานะมุกล้อโฆษณา "ผู้ช่วยนักวิจัย" และโดนเรียวยะแย้งทันที "อย่าเรียกจัง" — ตั้งใจ ไม่ใช่รั่ว ✅
- นาโอะ→ริสะ "ริสะจัง" สม่ำเสมอ (ch1:527, ch3:407, 513, ch4:153) และไม่พบจุดที่นาโอะใช้ "กู" พูดกับริสะ ✅ (เส้นที่ bible ล็อกไว้)
- นาโอะ→ไคโตะ "รุ่นพี่ไคโตะ"+"ผม" — และหลุดเป็น "ผม" เมื่อโดนไคโตะหยุดในบท 4 (ch4:701 "ผม...ผมไม่ได้จะ...") ตรงหมายเหตุ bible "เหมือนเด็กโดนว่า" ✅
- ริสะ→มิซากิ **"มิซาจัง"** ทุกจุด (ch1:785, 807; ch3:861; ch4:77) ✅ / ริสะ→ไคโตะ "ไคโตะคุง" / →เรียวยะ "เรียวยะคุง" / →นาโอะ "นาโอะคุง" ✅
- มิซากิ→ทุกคน ชื่อตรง + "แก" รวมถึงกับไคโตะ (ch3:725) ✅ / ไคโตะ→รุ่นน้อง ชื่อตรง (ch4:775) + โหมดคำสั้นตอนเครียด "พอ" "ออกดิ" ✅
- ชิอง→กลุ่ม "คุณ+ชื่อจริง" ถูกหมดทั้งสกุล (ch1:643 — อาราอิ/อามามิยะ/ซากุราบะ/อาซาฮินะ/คุโรซาวะ ตรงชื่อใน character_voices ทั้ง 5 ไฟล์) ✅
- เจ้าของเรียวกัง: "ท่านเจ้าของ" โดยทั่ว + นาโอะเรียก "ลุง" (ch2:47, ch3:447) ✅

### 2.5 ธีมซ้ำ (เทียบหมวด 3 ของ bible)

ปลูกครบตามแผน: กระดิ่ง (ch1:197-213 → ch4:1023), กลิ่นน้ำยาฆ่าเชื้อ (ch1:713 → เรียกคืนเบา ๆ ch3:295 ไม่ปลูกใหม่), การจำชื่อ (ch1:633-687), เชือกใหม่สามเส้นไม่มีกระดาษขอพร (ch3:1119-1143), ลายมือเอกสารพิพิธภัณฑ์เรียบร้อยผิดวัยกระดาษ (ch2:463-465), รองเท้าทำงานลายซิกแซก+คราบโคลนที่ธรณีประตู (ch1:235) → เชื่อมกับรอยเท้าโคลนแห้งบนฝุ่นบท 4 (ch4:749-759) — ปลูกเงียบตามแผน ไม่มีตัวละครสรุปแทนผู้อ่าน ✅

**ข้อสังเกต (ไม่ขัดแผนจนต้องแก้)**: motif กระดิ่งปรากับ 4 จุดใน 4 บท — บท 1 (เสียงจริง), บท 2 สองจุด (กระดิ่งพิธีในตู้พิพิธภัณฑ์ ch2:369-379 + มุกนาโอะเสนอเอาเสียงกระดิ่งทำซาวด์ ch2:997), บท 4 (ท้ายบท) — จุดพิพิธภัณฑ์เป็นของจริงในฉากที่ outline กำหนดเอง ส่วนมุก ch2:997 เป็นเสียงตัวละครอ้างถึง ไม่ใช่เหตุการณ์กายภาพ — ยังไม่ถึงระดับ "กระดิ่งเตือนภัย" ที่ bible เตือน แต่ควรระวังไม่เพิ่มอีกในบทถัดไป

### 2.6 การอ้างอิงเหตุการณ์ข้ามบท

ตรวจทุกการอ้างย้อนที่พบ: เสียงผู้หญิงคืนแรก (แก้แล้ว จุดที่ 2), กระดิ่งตอนลงรถ (ch2:997, ch2:381 ตรงกับ ch1:197-213) ✅, "นาโอะประกาศเมื่อคืนว่าจะไปดูจุดเริ่มเส้นทาง" (ch3:37 ตรงกับ ch2:975) ✅, "ห้าเวอร์ชัน" ที่นาโอะอ้างในบท 4 (ch4:63 นับได้ครบจากมุกประกาศผลบท 2) ✅, ตะปูหน้าต่าง/ประตูล็อกสองสถานะมิซากิ (ch4:445-449 กับ ch4:869-871 สอดคล้องกันเอง) ✅, จำนวนบ้าน 37 หลัง (เว็บเทศบาล) vs สิบกว่าหลัง (มองตอนกลางคืน) — ไม่ขัด ✅, รถเมล์สามเที่ยว+บ่ายเพิ่มวันหยุด (ch1:127) กับบัสบ่ายสามโมงอาทิตย์ (ch3:623) และเที่ยวสุดท้าย 18:00 จันทร์ (ch2:935) เข้ากัน ✅

## 3. จุดที่แก้แล้ว (surgical — แก้เฉพาะไฟล์บท)

1. **ch2:41 — เวลาอาหารเช้าวันเสาร์**: "ตอนเจ็ดโมงครึ่ง" → "ตอนแปดโมงครึ่ง" — มิซากิล็อกแผนไว้สองครั้งในบท 1 ว่า "ตื่นแปดโมง อาหารเช้าแปดโมงครึ่ง" (ch1:793, ch1:963); เสิร์ฟ 07:30 ทั้งที่นัดตื่น 08:00 ขัดกับแผนและกับเวลาถัดไปทั้งวันของบท 2 เอง
2. **ch2:215 — สภาพอากาศตอนได้ยินเสียง**: "ตอนที่ฝนเบาลงจนเกือบหยุด" → "หลังจากฝนเลิกไปแล้วนาน" — บท 1 ชัดว่าฝนเลิกก่อนจบมื้อค่ำ (ch1:777) และตอนเสียงดัง (23:11) เรียวยะบอกเองว่า "ฝนเลิกนานแล้ว" (ch1:1083)
3. **ch3:309 — "เมื่อวาน" ผิดหนึ่งวัน**: "หาไม่เจอตั้งแต่เมื่อวานตอนนั่งรถมา" → "ตั้งแต่วันแรกตอนนั่งรถมา" — การนั่งรถมาคือวันศุกร์ (บท 1) ส่วนฉากนี้เป็นวันอาทิตย์ (ยืนยันจาก ch3:617) ห่างกันสองวัน
4. **ch3:799 — นาโอะแย้งตัวเองเรื่องที่มาข้อมูลเส้นทางปิด**: "ฉันถามพี่แกตอนเอามา แกบอกว่า" → "พี่แกบอกตอนเอามาให้ว่า" — ในบท 2 นาโอะตอบไคโตะว่า "อันนั้นกูไม่รู้ว่ะ ไม่ได้ถาม" (ch2:899); ให้พี่แกเล่ามาเอง (สาเหตุ=พายุ ไม่บอกปี) แล้วทั้งสองบทเข้ากันได้
5. **ch4:895 — ที่หยิบแผนที่**: "หยิบอะไรออกมาจากกระเป๋ากางเกง" → "จากซองเอกสาร" — แผนที่คือ "กระดาษแผ่นใหญ่ที่พับเป็นสี่ทบ" ที่ต้องกางกดมุมด้วยถ้วยซุป (ch3:777-779) และเคยเก็บในซองเอกสาร (ch3:307) — ใส่กระเป๋ากางเกงไม่ได้ทั้งขนาดและที่เก็บที่ปลูกไว้
6. **ch4:55 — กันความกำกวมเวลาตะวันตก**: "ตะวันตกหกโมงสิบ" → "วันนี้ตะวันตกหกโมงสิบ" — ประโยคอยู่ตอนเพิ่งเข้าบ้าน (~16:10 ต่อจาก ch3:1289) และตอนออกคือ 17:45 (ch4:495); ถ้าอ่านเป็นเวลาปัจจุบัน 18:10 จะขัดทั้งบท — ชี้ชัดว่าเป็นเวลาพระอาทิตย์ตกของวัน (สอดคล้องท่านเจ้าของ "ห้าโมงห้าสิบก็มืด" ch3:883 = แสงหมดก่อนตะวันตกจริงเพราะถูกยอดเขาบัง ตาม bible 7.4)

## 4. ประเด็นค้าง (remainingConcerns — ต้อง owner ตัดสินเชิงสร้างสรรค์)

1. **ไฟฉาย 2 ดอกของไคโตะหายไปจากบท 4** — บท 3 ปลูกชัด "ไฟฉายสองดอกพร้อมถ่านสำรองสี่ก้อน" จัดเป็นชุดของเตรียมตัว (ch3:819-827) แต่บท 4 ทุกคนใช้ "แสงไฟฉายจากมือถือห้าเครื่อง" ตลอด (ch4:11, 99) และคำสั่งมิซากิ "เก็บไฟฉาย คงไว้สองดวง" (ch4:889-891) วัดจากบริบทคือไฟมือถือ — ตัวละครเผื่อถ่านมาแล้วไม่ใช้เลย เกี่ยวกับ bible ที่วางไว้ว่า Arc 2 "แบตเสื่อมจากไฟฉาย" — ทางเลือก: ลบไฟฉายออกจากบท 3 / ให้ใช้จริงในบท 4-5 (ต้องแก้หลายจุด ไม่ใช่ surgical จุดเดียว) / อธิบายว่าลืมอยู่ในเป้ — เกินขอบเขตบรรณากรตัดสินเอง
2. **ความกำกวมที่ตั้งถิ่นฐานตัวละคร** — บท 2 มี "กลับไปกรุงเทพฯ" สองจุด (ch2:145, ch2:979) และ "คนกรุงเทพฯ ชอบเรื่องนี้" ขณะที่ฉากทั้งหมดเป็นญี่ปุ่น (นากาโน่ ม.ชินชู ch2:835-839, ป้าย "ภาษาญี่ปุ่น" ch2:595, ชื่อ-สกุลญี่ปุ่นทั้งกลุ่ม) — ไม่มี setting_bible ในชุดที่ได้รับมาตรวจ จึงไม่ตัดสินแทนว่าตัวละครเป็นนักศึกษาไทยในญี่ปุ่น หรือเป็นไทยล้วน (ซึ่งจะขัดฉากนากาโน่) หรือเป็นการ localization โดยตั้งใจ
3. **ไคโตะใส่ "รองเท้าทำงาน" ขึ้นเขา (ch4:15, ch4:749)** — ทำให้ motif รองเท้าทำงานของชิอง (ch1:235) ที่ถูกออกแบบให้เป็นหลักฐานเชื่อมบท 11 เบลอลง และรอยเท้าปริศนาในบท 4 ("เหมือนพื้นรองเท้าทำงาน" ch4:753) อาจถูกอ่านว่าเป็นของไคโตะ — text กันไว้แล้วด้วยการแยกบรรยายรอยสองแบบชัดเจน (ch4:749 vs 753) แต่ถ้าไม่ได้ตั้งใจเป็น red herring ควรเปลี่ยนรองเท้าไคโตะเป็นรองเท้าผ้าใบ/รองเท้าเดินป่า — เป็นเจตนาที่ต้องยืนยัน
4. **"ฝนหยุดตั้งแต่ตีสี่" ของท่านเจ้าของ (ch2:45)** — บท 1 ฝนเลิกตั้งแต่ก่อน ~21:00 ของคืนก่อน (ch1:777) — ยืดได้ถ้ามีฝนชุดใหม่ช่วงเช้ามืดที่เรียวยะหลับไม่รู้ แต่ไม่มีหลักฐานในเนื้อเรื่องรองรับ; อาจแก้เป็น "ฝนหยุดตั้งแต่เมื่อคืน" หรือทิ้งไว้ให้เป็นวาทะคนแก่พูดคร่าว ๆ — ผมเลือกไม่แกะเพราะเป็นคำพูดตัวละครที่ตีความได้สองทาง
5. **ความยืดของช่วงเวลาสำรวจภายในบ้าน (บท 4)** — จากจุดเริ่มนับ 20 นาทีแรกหมดตอนถึงโถงกลาง (ch4:293) ถึงเวลา 17:45 ก่อนออก (ch4:495) มีระยะ ~75 นาที ทั้งที่กฎคือรอบละ 10 นาทีพบกันที่โถงกลาง — เนื้อเรื่องเล่าแบบย่อข้ามรอบ (นับตัวจับเวลาที่ปรากฏชัด = ครบ 3 รอบพอดี ch4:955) จึงอ่านไหลได้ แต่ถ้าต้องการเวลาแน่นระดับบท 3 อาจต้องใส่หมุดเวลาคั่นกลางเพิ่ม — เชิงจังหวะการเล่า เกิน surgical
