## 1. ตารางการเรียกชื่อ (Address Sheet)

หลักการ: ทุกคำเรียกต้องอ่านแล้วแยกตัวละครได้โดยไม่ต้องมีป้ายชื่อ (สัญญาข้อ 8) — เสียง มุมมอง คำติดปากต่างกันชัด

### 1.1 คำเรียก + สรรพนาม

| ผู้พูด → ผู้ฟัง | คำเรียก | สรรพนามตัวเอง | หมายเหตุเสียง/มุก |
| :--- | :--- | :--- | :--- |
| นาโอะ → เรียวยะ | "มึง" / "เรียวยะ" | "กู" | มุกประจำคู่: นาโอะเรียกเรียวยะ "ทนายความ" ตอนเรียวยะเริ่มไล่ลำดับข้อมูล |
| นาโอะ → มิซากิ | "หัวหน้าทริป" (แซว) / "มิซากิจัง" | "กู" | มิซากิไม่ขำ แต่ก็ไม่ห้าม — มุกเด้ง: เขาเรียกคนเดียวที่เธอได้ยินทุกวี่ทุกวัน |
| นาโอะ → ริสะ | "ริสะจัง" | "ฉัน" | นาโอะไม่ใช้ "กู" กับริสะ — เส้นที่เขายังรักษาโดยไม่รู้ตัว |
| นาโอะ → ไคโตะ | "รุ่นพี่ไคโตะ" | "ผม" (ล้อเลียนฟอร์มัล) | ถ้าไคโตะจริงจัง นาโอะหลุดเป็น "ผม" เหมือนเด็กโดนว่า |
| เรียวยะ → นาโอะ | "นาย" / "นายนาโอะ" (ตอนจริงจัง) | "ฉัน" | ตาม voice: "นายบอกว่าแค่ลองดี" |
| เรียวยะ → ริสะ/มิซากิ | "ริสะ" / "มิซากิ" | "ฉัน" | เรียกชื่อตรง เพื่อนปีเดียวกัน |
| เรียวยะ → ไคโตะ | "รุ่นพี่ไคโตะ" | "ฉัน" | สุภาพแต่ไม่ใกล้ชิด — ระยะห่างที่ไคโตะวางไว้ก่อนแล้ว |
| มิซากิ → ทุกคน | ชื่อตรง + "แก" | "ฉัน" | ใช้ "แก" กับทุกคนรวมถึงไคโตะ (voice file: เป็นกลาง ไม่ได้หยาบ) |
| มิซากิ → ริสะ | "ริสะ" (เสียงนุ่มลงจับจังหวะได้) | "ฉัน" | อ่อนลงกับริสะคนเดียว — ผู้อ่านต้องรู้สึกได้จากจังหวะ ไม่ใช่คำ |
| ริสะ → มิซากิ | **"มิซาจัง"** | "ฉัน…ค่ะ" | ล็อกโดย owner |
| ริสะ → ไคโตะ | "ไคโตะคุง" | "ฉัน" + คะ/ค่ะ | นุ่มที่สุดในกลุ่มเสียงของริสะ |
| ริสะ → เรียวยะ/นาโอะ | "เรียวยะคุง" / "นาโอะคุง" | "ฉัน" + คะ/ค่ะ | สุภาพติดนิสัยทุกคน |
| ไคโตะ → ริสะ | "ริสะ" | "ฉัน" | เสียงทุ้ม พูดช้า — "ริสะอยู่ข้างหลังฉัน" |
| ไคโตะ → รุ่นน้อง | ชื่อตรง ("นาโอะ" "เรียวยะ") | "ฉัน" | ตอนเครียดหลุดเป็น "แก" + ประโยคสั้น ("หยุด" "พอ") — Arc 1 ให้เห็นแค่ปลายทางของโหมดนี้ |
| ไคโตะ → มิซากิ | "มิซากิ" | "ฉัน" | สนิทระดับเพื่อนแฟน — คู่สนทนาเงียบ ๆ ของโต๊ะอาหาร |
| ทุกคน → ชิอง | "ชิองซัง" | — | แขกต่อคนช่วยงานเรียวกัง |
| ชิอง → กลุ่ม | "คุณเรียวยะ" "คุณริสะ" ฯลฯ (ชื่อจริง ถูกต้อง ไม่ต้องถามซ้ำ) | "ผม" + ครับ | จำชื่อแขกทุกคนได้ตั้งแต่เห็นสมุดจองครั้งเดียว — นี่คือหน้ากากที่หมู่บ้านชื่นชม และคือ seed ที่เรียวยะจะจับได้เฉย ๆ ในบท 1 |
| ทุกคน → เจ้าของเรียวกัง | "ท่านเจ้าของ" (นาโอะเรียก "ลุง" สนิทแบบมั่น) | — | |
| นาโอะ → อากิระ (เล่าให้ฟัง) | "รุ่นพี่อากิระ" | — | ดูหมวด 5 |

### 1.2 กฎเหล็กของบทสนทนาหลายคน

- มิซากิ = ประโยคคำสั่งสั้น ไม่มีคำลงท้ายนุ่ม ๆ / ริสะ = คะ-ค่ะ + ประโยคไม่จบตอนกลัว / นาโอะ = ว่ะ-ดิ-เหรอ พูดเร็ว / ไคโตะ = คำสุภาพสั้น เด็ดขาดขึ้นเมื่อเป็นห่วงริสะ / เรียวยะ = ประโยคคำถาม + นะ-มั้ง
- มุกกลุ่มเกิดจากการเด้ง: นาโอะโยน → มิซากิตัด → ริสะขำแหบ ๆ → ไคโตะเปลี่ยนเรื่องให้ริสะ — ไม่ใช่ให้ narrator บอกว่า "ทุกคนหัวเราะ"
- ห้ามให้ทุกคนพูดสุภาพเท่ากันในฉากผ่อนคลาย — โทนบท 1-2 เบาและมีชีวิต (voice_principles: ต้นเรื่องเบา มีชีวิตชีวา)

## 2. ตารางเวลา Arc 1 (Schedule Decision)

### 2.1 ความกำกวมที่ต้องตัดสิน

- timeline.md (บรรทัด DAY 1): กลุ่ม "มาถึงเช้า" วันแรก → บ่ายปูความสัมพันธ์ → เย็นข่าวลือ → กลางคืนเงาชุดขาว → เช้าวันสองของหาย → สายวันสองเข้าบ้าน
- chapter_outlines.md (บท 1): "เย็นวันศุกร์ ฝนปรอย" มาถึง + อาหารค่ำเจอชิอง + คืนนั้นนอนห้องพัก → บท 2 "เช้าวันเสาร์" → บท 3 "เช้าวันเสาร์สายถึงบ่าย" (ชนกับบท 2 ในวันเดียว)

### 2.2 คำตัดสิน

**ยึดฝั่ง chapter_outlines.md และขยายเป็น 3 วันเต็ม** — มาถึง "เย็นวันศุกร์" ตาม outline (สมเหตุสมผลกว่า: นักศึกษาออกเดินทางหลังเรียน/ทำงานเสร็จ 2-3 ชั่วโมงถึงชนบท เหลือเวลาแค่อาหารค่ำ+คืนแรก ซึ่งทำให้ฉากอาหารค่ำกับชิองเกิดโดยธรรมชาติ) และแยกบท 2 กับบท 3 เป็นคนละวัน เพื่อไม่ให้บท 3 ถูกบีบให้จบในเช้าวันเดียวกับบท 2

ผลลัพธ์: Arc 1 = ศุกร์เย็น → จันทร์เช้า (3 คืน) — timeline.md ช่อง DAY 1 "เช้า" ให้ถือว่าตกไป และเพิ่มวันคั่นหนึ่งวันระหว่างข่าวลือกับการขึ้นเขา (เมื่อทำ revision ไฟล์ timeline ให้แก้ DAY 1 = ศุกร์เย็นมาถึง / DAY 2 = เสาร์ข่าวลือ / DAY 3 = อาทิตย์ขึ้นเขา — ช่วง Arc 2-3 ทั้งหมดยังอยู่ใน "คืนวันอาทิตย์→เช้าจันทร์" ตามสัดส่วนเดิมของ timeline)

เหตุผลที่ลื่อสุด:
1. บท 1 ได้ฤกษ์เปิดเรื่องแบบทริปจริง (รถมาถึงตอนฟ้ามืด ฝนปรอย — เข้ากับ setting_bible "วันที่กลุ่มมาถึง ฝนปรอย")
2. เสาร์ทั้งวันเป็น "วันของข่าวลือ" — กลุ่มมีเวลาถามชาวบ้านหลายเวอร์ชันจริง ๆ ไม่ใช่รีบ ๆ ตอนเช้า
3. ของหายเช้าอาทิตย์ + ขึ้นเขาบ่ายอาทิตย์ = กลุ่มตั้งใจ "ลงก่อนตะวันตก" แต่ประตูปิดตอนแสงเริ่มหมด — เข้าข่ายข่าวลือ "ใครขึ้นไปหลังตะวันตกจะไม่ได้กลับลงมา" พอดีเป๊ะ โดยไม่ต้องให้ตัวละครโง่
4. ฤดู: ปลายฤดูร้อน (พักร้อน) — เข้ากับ prologue "เดือนที่อากาศยังอุ่น" และความเย็นชื้นบนเขาได้ทั้งคู่

จุดที่ต้องปลูกแบบ "เงียบ ๆ" เพื่อ Arc 2-3 (อย่าให้ตัวละครสรุปให้คนอ่าน):
- ลายมือเรียบร้อยในเอกสารพิพิธภัณฑ์ (บท 2) — จะกลับมาเป็น clue ลายมือสมุดบันทึก (บท 11)
- รอยพื้นรองเท้าทำงานของชิอง ที่โต๊ะรองเรียวกัง (บท 1) — จะกลับมาเทียบรอยเท้าบนโคลน (บท 4 เห็น / บท 11 เชื่อม)
- ความรู้เรื่องทางขึ้นเขาของชิองละเอียดเกินคนอยู่แค่ 2 ปีครึ่ง (บท 1-2)

## 4. ประเด็นสร้างสรรค์ต่อบท 1-4 (ไอเดีย original — ไม่มีใน outline)

outline คือทิศทาง ไม่ใช่สคริปต์ (สัญญาข้อ 3) — ทุกไอเดียนี้เสริมจุดหมายบท (Starting→Ending Status) โดยไม่เปลี่ยนจุดหมาย

### บทที่ 1: เรียวกังฮิโนะโมริ

1. **ป้ายกฎทริปของมิซากิ** — มิซากิทำป้ายกระดาษ "กฎทริป 3 ข้อ" ติดที่ประตูห้องอาหาร (1. รวมกลุ่มก่อนแยกย้าย 2. บอกคนอื่นเสมอ 3. เวลาสามทุ่มอยู่ที่เรียวกัง) — มุกกลุ่ม: นาโอะอ่านจบแล้วขอเพิ่มข้อ 4 "สนุกให้สุด" โดนมิซากิฉีกทิ้ง → เสริม: กฎข้อ 1-2 จะกลายเป็นเรื่องขมขื่นในบท 6 ที่กลุ่มละเมิดทั้งสองข้อโดยไม่รู้ตัว — และคนอ่านจะจำได้
2. **ฉากอาบน้ำร้อนสั้น ๆ ก่อนอาหารค่ำ** — บ่อเล็ก หมอกลาง ฝนปรอยเป็นเสียงกิ่งไม้รอบบ่อ — ปูไดนามิกโดยไม่ต้องรอโต๊ะอาหาร: ไคโตะขึ้นก่อนเพื่อไปเช็กห้องให้ริสะ ริสะว่า "ไม่เป็นไรค่ะ" เบา ๆ มิซากิเหลือบมอง / นาโอะอวดการลอยตัวจนโดนน้ำเข้าปาก → เสริม: ความสัมพันธ์ passive control ไคโตะ-ริสะ ถูก "เห็น" ก่อนถูก "เล่า" และ Scene 1.2 จะมีทุกคนสดชื่นพร้อมกัน
3. **เกมจำชื่อบนโต๊ะอาหาร** — นาโอะท้าชิองว่าจำชื่อจริงไหม ชิองเรียกได้ทุกคนรวมทั้งนามสกุล แล้วพูดว่า "ชื่อเป็นสิ่งที่ควรเรียกให้ถูกครับ" น้ำเสียงธรรมดา — ริสะหัวเราะ เรียวยะจดในใจว่าคนนี้สังเกตเก่ง → เสริม: ปลูก motif การเรียกชื่อ + ให้ชิองได้จ้องกลุ่มแบบเปิดหน้าครั้งแรก (ภายใต้หน้ากากธรรมดา) และเรียวยะเริ่มมีข้อมูลชิ้นแรกโดยยังไม่รู้ตัว
4. **ครึ่งนาทีเงียบของนาโอะ (Scene 1.3)** — ก่อนหลับ นาโอะเงียบผิดจุดเป็นครึ่งนาที แล้วถามเรียวยะ (ที่คิดว่าหลับแล้ว) ว่า "มึงว่าบ้านผีมีจริงไหม" — น้ำเสียงไม่มีมุกเลย — แล้วเดี๋ยวนั้นกลับมาเป็นนาโอะเดิม: "เออ ว่าแต่พรุ่งนี้กินอะไรดีวะ" → เสริม: วางความกลัวความเงียบของนาโอะ (wound) แบบไม่เฉลยต้นเหตุ และทำให้คนอ่านรู้ว่ามุกของเขาคือเกราะ ไม่ใช่ความไร้เดียงสา
5. **ผ้าพันคอตัวแรก** — อากาศเย็นลงตอนค่ำ ริสะหยิบผ้าพันคอออกมาใส่ มิซากิแซวว่า "ยังกันยายเลย" — ริสะบอกว่ามิซากิเลือกให้เองตอนวันเกิด มิซากิเงียบไปเสี้ยววินาทีแล้วเมินพูดเรื่องอื่น → เสริม: ปูวัตถุของบท 3 ให้มีน้ำหนักอารมณ์ ไม่ใช่แค่ "ของหาย" และเผยว่ามิซากิให้อะไรกับริสะด้วยวิธีของเธอ

### บทที่ 2: ข่าวลือเจ้าสาวบนเขา

1. **ฉากพิพิธภัณฑ์ท้องถิ่น** (สาย) — ชิองพาชม: ชุดกิโมโนขาวจำลอง เครื่องมือพิธีบูชายัญเก่า แผ่นพับ "ประวัติทางเดินป่า" — เรียวยะสังเกตว่าแผ่นพับเรียงมือใหม่เกินอายุกระดาษ แต่คิดว่าคงมีคนดูแลดี → เสริม: ปลูก clue ลายมือ + ทำให้ความรู้ของชิอง "มีที่มา" ในสายตากลุ่ม และให้ริสะได้เห็นชุดขาวจำลอง = เงาชุดขาวตอนบ่ายจะชนกับภาพในหัวเธอ
2. **มุกตารางข่าวลือ 5 เวอร์ชัน** (ค่ำ) — นาโอะรวบรวมข่าวลือทั้งวันมาทำตารางบนสมุด อ่านให้ฟังตอนอาหารค่ำ พร้อมประกาศ "รางวัลข่าวลือยอดเยี่ยม" ให้ป้าที่เล่าเรื่อง "ถ้าเธอโค้งให้ห้ามโค้งกลับ" — มิซากิถามตรง: "แปลว่าไม่มีใครรู้เรื่องจริงสักคนใช่ไหม" — โต๊ะเงียบกึก → เสริม: ให้คนอ่านจำทั้ง 5 เวอร์ชันได้ในฉากเดียว + มุกนี้คือจุดที่ความกลัว "เข้าบ้าน" ครั้งแรกโดยที่ทุกคนยังหัวเราะอยู่
3. **ความจำไม่ตรงกันของชาวบ้านเรื่องชิอง** — ป้าแถวร้านขายของพูดว่า "มาโดกะคุงมาอยู่ที่นี่นานแล้ว สี่ปีได้มั้ง" อีกคนแก้ว่า "สองปีได้ มาหลังงานศพในหมู่บ้านนี่แหละ" — แล้วทั้งคู่เถียงกันเรื่องอื่นต่อ → เสริม: ขยายธีม "ข่าวลือไม่ตรงกัน" ให้แตะตัวชิองเองโดยไม่ร้องเตือนคนอ่าน (ความจริงตาม setting: ~2 ปีครึ่ง) — เรียวยะได้ยินแต่ไม่มีอะไรผิดปกติพอจะเก็บ
4. **ริสะถามมิซากิเบา ๆ หลังเห็นเงา** — หลังเหตุการณ์เงาชุดขาว ริสะดึงมิซากิไว้ถาม "มิซาจัง…เมื่อกี้ มีใครยืนตรงนั้นไหม" มิซากิมอง — ไม่มีใคร — ริสะยิ้มว่า "ไม่เป็นไรค่ะ คงตาฝาด" แล้วเดินนำ — มิซากิมองหลังสองวินาทีก่อนตาม → เสริม: ปู mask ของริสะ (ยิ้มกลบเพราะกลัวเป็นภาระ) และปูสัญชาตญาณ "มิซากิปกป้องริสะ" ที่จะพังในบท 8-9
5. **เสียงหญิงร้องคืนแรก ย้อนเฉย ๆ** — ตอนเงาชุดขาว/กลับห้อง มี beat สั้น: เรียวยะนึกขึ้นได้ว่าเสียงผู้หญิงที่ได้ยินเมื่อคืน (Scene 1.3) หายไปคืนนี้ — เขาไม่รู้ว่าแปลว่าอะไร แค่จดว่า "มันไม่ต่อเนื่อง" → เสริม: ให้สมองนักสังเกตของเรียวยะทำงานแบบสมจริง (ข้อมูลแบบคน ไม่ใช่นักสืบ) และวาง pattern เสียงเทป/เสียงจริงที่จะสำคัญใน Arc 2

### บทที่ 3: ของที่หาย

1. **ฉากหาของกลับบ้าน** — กลุ่มกลับห้องกลับกระเป๋า: นาโอะกลับกระเป๋าทุกใบเป็นเขาวงกต ไคโตะเดินไล่ตรวจรอบเรียวกัง มิซากิไล่เช็ก "ใครเห็นล่าสุด" แบบสอบปากคำเป็นระบบ — ริสะยืนกลางห้อง ขอโทษซ้ำ ๆ จนมิซากิหยุด: "ไม่ใช่ความผิดแก" (เสียงนุ่มกับริสะคนเดียว) → เสริม: ให้ทุกคนแสดงวิธีคิดผ่านวิธีหาของ (เรียวยะจดลำดับครั้งสุดท้ายที่เห็นผ้าพันคอ = สายวันนี้ หน้าบ่อ) — และปู "ริสะรู้สึกผิลที่ทำให้ทุกคนวุ่นวาย" ตาม outline
2. **โหวตกระดาษของมิซากิ** — ตัดสินใจไม่ได้ มิซากิฉีกกระดาษแจกให้เขียนชื่อ "เห็นด้วยกับการขึ้นเขาหรือไม่" — ไคโตะเขียนสองชื่อในครั้งเดียว: "ไคโตะ + ริสะ" โดยไม่ถามเธอ — ริสะมองชื่อตัวเองที่ลายมือคนอื่นเขียน แล้ววาดดอกจันเล็ก ๆ ต่อท้าย (ยังไม่ขัด — แค่อึกอัก) → เสริม: ทำให้ "ไคโตะตัดสินใจแทน" ปรากฏเป็นภาพจับต้องได้ก่อนเข้าบ้าน — payoff ที่ห้องสองประตู (บท 6) จะได้ไม่ใช่ข่าวใหม่ แต่คือรอยแตกที่คนอ่านเห็นมาแล้ว
3. **ศาลเจ้าเก่าครึ่งทาง** — พักที่ศาล (จุดสังเกตบนเขาตาม setting_bible): นาโอะผูกเชือกขอพรแซวว่า "ขอเจอผีจริง ๆ ขอแบบมีคลิปด้วย" — เรียวยะเหลือบเห็นเชือกส่วนใหญ่ซีดจนเกือบดำ แต่มีเชือกใหม่ไม่กี่เส้นที่ผูกประณีตผิดปกติ และไม่มีคำอธิษฐานเลย แค่ผูกแน่น ๆ รอบกิ่ง → เสริม: เย็นลงเรื่อย ๆ โดยไม่ต้องมีผีโผล่ — "มีคนขึ้นมาที่นี่บ่อยเกินกว่าคนธรรมดาจะขอพร" คือความผิดปกติแรกบนเขาที่เรียวยะเก็บได้
4. **ป้ายไม้ที่ถูกขูด** — ที่ป้ายไม้ใกล้ทางขึ้น (outline seed) เรียวยะลูบรอยแล้วพูดกับตัวเองว่า "ขูดจากบนลงล่าง จบในทีเดียว ไม่ใช่ฝนกัด" — นาโอะถามว่ามึงพูดอะไรวะ — เรียวยะว่าไม่มีอะไร → เสริม: ผูกกับ prologue (เหยื่อ "คนที่ 11" นึกถึงป้ายนี้ตอนน้ำท่วมอก) โดยคนอ่านที่อ่าน prologue จะขนลุกเอง โดยตัวละครไม่รู้อะไรเลย
5. **มือถือตายทีละเครื่อง** — ระหว่างทางขึ้น สัญญาณหายตั้งแต่กลางทาง (setting bible) — beat เล็ก: ไคโตะเป็นคนเช็กถี่ที่สุด ยืนยันกับริสะว่า "ถ้ามีอะไร เดี๋ยวรีบลง" น้ำเสียงมั่นใจ — มิซากิมองแท่งสัญญาณของทุกเครื่องแล้วสรุปสั้น: "ต่อให้มีสัญญาณ ฝนก็ทำเสาพัด" → เสริม: ปิดช่อง "ทำไมไม่โทร" ล่วงหน้าแบบมีชีวิต ไม่ใช่บทสรุป — และเพิ่มความหวังลม ๆ แดด ๆ ของไคโตะให้ชัดก่อนแตก

### บทที่ 4: บ้านคุซาบิ

1. **ไกด์นาโอะ กับคลิปที่จบเอง** — นาโอะเดินนำถ่ายคลิป เสียงผู้กำกับ: "สวัสดีครับทางบ้าน วันนี้เรามาที่บ้านคุซาบิ—" มุกไกด์เดินไปเรื่อยจนเจอรอยเลือดเก่าบนธรณีประตู เขาหยุดพูดกลางประโยค กดหยุดถ่ายเอง — ไม่มีใครพูดอะไร → เสริม: จังหวะ "เสียงนาโอะที่หายไป" คือครั้งแรกที่ความสยองชนะมุก โดยไม่ต้องมี narrator บอกว่าอันตราย (และเป็น seed ของ Arc 2: มุกที่เริ่มไม่เวิร์ค)
2. **ถ้วยสองใบที่ตากแห้ง** — ห้องครัว: ทุกพื้นผิวจมฝุ่น แต่มีถ้วย 2 ใบวางกลับหัวบนตะเกียบ เรียวยะยกดู — วงแหวนใต้ถ้วยสะอาด ฝุ่นไม่เกินหนึ่งคืนฝน — เขาวางกลับตามเดิมทุกมิลลิเมตรโดยไม่รู้ตัวว่าทำไม → เสริม: clue แบบนักสังเกตที่ไม่เฉลย (มีคนอยู่ที่บ้านเมื่อเร็ว ๆ นี้ — คู่หนึ่งของเหยื่อกระจัดกระจายรายล่าสุด หรือชิองเอง) และพฤติกรรม "วางกลับเป๊ะ" คือ DNA ของเรียวยะที่คนอ่านจะเห็นทำงานครั้งแรกบนของจริง
3. **มิซากิวางกฎในบ้าน** — ก่อนแยกสำรวจ มิซากิประกาศ: "เจอกันที่โถงกลาง ทุก 10 นาที ห้ามแยกเดี่ยว" — นาโอะทำมือให้ทหาร — ครั้งนี้ไม่มีใครขำเพราะบ้านเงียบเกิน → เสริม: สอนผังบ้านชั้น 1 ให้คนอ่านคุ้นก่อนกับดัก (ห้องเสียง/โถงกลาง/บันได จะเป็นสนามจริงในบท 5) และ echo กฎทริปข้อ 1-2 จากบท 1 ให้คนอ่านใจหายเองว่ากฎกำลังจะถูกละเมิด
4. **เทปม้วนแรก** — นาโอะหาเครื่องเล่นเทปในห้องนั่งเล่น กดเล่นเพื่อมุก "เสียงผี" — เทปเริ่มด้วยเสียงผู้หญิงพูดธรรมดาจน ๆ ("…พอแล้ว วันนี้แค่นี้แหละ…") แล้วตัดเป็นเสียงเคาะ เบา สม่ำเสมอ ไม่หยุด — ไคโตะกดปิดเอง พูดว่า "พอ" — ครั้งแรกที่ไคโตะใช้คำสั่งกับกลุ่ม → เสริม: ปลูกเสียงเคาะ (อนาคตของอายาเมะ) โดยวลีธรรมดาต้นเทปทำให้คนอ่านรู้สึกว่าเทปนี้เคยเป็น "คน" — และให้ไคโตะข้ามเส้นจากผู้ดูแลเป็นผู้สั่งครั้งแรกเบา ๆ
5. **ริสะมองเห็นหน้าต่างชั้นสอง** — ตอนทุกคนรวมกลุ่มจะออก (Scene 4.3 ก่อนค้นพบว่าประตูล็อก) ริสะหันไปทางตัวบ้านเพื่อจะบอกว่าเธอเห็นอะไรบางอย่างผ่านหน้าต่างชั้นสอง — แต่ประตูหน้าดังปิดตึงเสียก่อนที่เธอจะเริ่มประโยค → เสริม: จบ Arc ด้วยสองชั้น: "ติดบ้าน" + "มีบางอย่างที่ริสะยังไม่ได้บอก" — ความเงียบของเธอจะต่อยอดเป็นความรู้สึก "ถูกจับตามอง" ของบท 2 และเป็นวัตถุดิบความกลัวริสะใน Arc 2 โดยไม่ต้องเฉลยว่าเธอเห็นอะไร (ให้คงกำกวม — ตามหลักเงาชุดขาว มองไม่ชัด)

## 5. การเดินสาย Crossover: นาโอะเล่าเรื่องรุ่นพี่อากิระ (Easter Egg Beat 1)

ข้อมูล canon (จาก timeline.md + cast_biography.md + series_outline.md): **ซูซูกิ อากิระ — อายุ 21 (เกิด 1991) — ปี 4 มหาวิทยาลัยชินชู (นากาโน่) — รุ่นพี่ที่สนิทกับนาโอะผ่านความชอบเว็บบอร์ด 2ch และตำนานพื้นบ้านนากาโน่ — เคยเล่าว่าสมัย ม.ปลาย ตนกับเพื่อนเจอเรื่องผีบนเขาแถบนากาโน่จริง ๆ — เป็นคนช่วยค้นแผนที่ทางเดินป่าเก่าจากหอสมุดมหาลัยให้นาโอะ**

### 5.1 ตำแหน่งฉาก

- **ฉากหลัก: บท 2 ตอนค่ำวันเสาร์** — หลังมุกตารางข่าวลือ (ไอเดีย 4.2) ตอนกลุ่มยังนั่งรอบโต๊ะอาหาร/ครัวรวมของเรียวกัง — ไฟอุ่น ฝนนอกหน้าต่าง — ช่วงเปลี่ยนอารมณ์จากหัวเราะเป็นเงียบฟัง ยาว ~1-1.5 หน้า ไม่เกิน
- **ฉากรอง: บท 3 ตอนเตรียมขึ้นเขา** — นาโอะหยิบสำเนาแผนที่ทางเดินป่าเก่า (พับมา 4 ทบ) ออกจากกระเป๋า อวดว่า "ของรุ่นพี่อากิระ" — แผนที่นี้คือเหตุผลที่กลุ่มกล้าขึ้นเขาเส้นที่ไม่มีใครรู้จัก — ใช้เป็น prop ต่อเนื่อง ไม่ต้องเล่าซ้ำ

### 5.2 วิธีเล่า (ผูกกับ voice ของนาโอะ)

- นาโอะเล่า **กึ่งเชื่อครึ่งไม่เชื่อ**: โทนตื่นเต้นสนุก ๆ แต่มีจังหวะที่เขาเล่าเร็วผิดปกติ — "เอาจริง ๆ พี่แกเล่าตอนเมาอ่ะ กูก็ไม่รู้สิว่าจริงไหม แต่พี่แกหน้าตาจริงจังว่ะ…"
- เนื้อที่นาโอะเล่าได้ (ทั้งหมดที่เขารู้):
  1. รุ่นพี่อากิระคนนี้อยู่มหาลัยที่นากาโน่ เจอกันตอนนาโอะไปค้นเรื่องตำนานพื้นบ้านบนเว็บบอร์ด แล้มาเจอกันตัวจริงที่คลับ/กิจกรรม
  2. อากิระเล่าว่า **สมัย ม.ปลาย เขากับเพื่อนสนิทเคยเจอเรื่องผีบนเขาแถบนากาโน่จริง ๆ** — เล่าถึงตอนที่เขารอเพื่อนคนเดียว ก่อนหยุดโดยไม่บอกชื่อหรือรายละเอียดที่เหลือ
  3. อากิระเป็นคน **ช่วยค้นแผนที่ทางเดินป่าเก่าจากหอสมุดมหาลัย** ให้ — ต้นฉบับเป็นเอกสารเก่ามาก ทางเดินสมัยที่เส้นทางบางเส้นยังเปิดใช้ (ปลูกเบา ๆ ว่ายุคต้น 90s — คนอ่านที่จำ Epilogue ได้จะจับลิงก์ 1991 เอง โดยตัวละครไม่เน้นปี)
- ปฏิกิริยากลุ่ม: มิซากิตัด: "แผนที่เก่ายิ่งไม่น่าเชื่อ เส้นทางมันเปลี่ยน" / ไคโตะไม่สนใจเรื่องผี แต่สนใจคำว่า "ทางปิดไปแล้ว" / ริสะฟังเงียบ ๆ แล้วถามนาโอะเบา ๆ ว่า "แล้ว…รุ่นพี่คนนั้นรอดไหมคะ" — นาโอะหยุดกึก ตอบว่า "…รอดสิ ไม่งั้นใครจะเล่าให้กูฟังว่ะ" แล้วหัวเราะแห้ง ๆ → คำถามของริสะคือ beat ที่ทำให้คนอ่านขนลุกโดยไม่มีใครตาย
- POV กรองผ่านเรียวยะ: เขาจดสองอย่างเฉย ๆ — (1) นาโอะเล่าเรื่องผีแบบมีแหล่งข้อมูลจริงเป็นครั้งแรก (2) แผนที่ทางเดินเก่ามีอยู่จริงในกระเป๋านาโอะ — ยังไม่เชื่อมกับอะไรทั้งนั้น

### 5.3 ขอบเขตเหล็กของ crossover

- ❌ ห้ามเอ่ยชื่อเรื่องอื่น / ชื่อเพื่อนของอากิระ / รายละเอียดเหตุการณ์บนเขาเพิ่มเติม (นาโอะรู้เพียงว่าอากิระรอเพื่อนคนเดียวแล้วเจออะไรบางอย่าง — อากิระเล่าไม่จบ)
- ❌ ห้ามให้อากิระโผล่ตัวจริงหรือโทรมาใน Arc 1 — เขามีอยู่ในบทสนทนาเท่านั้น
- ✅ ใช้จริงได้: ชื่อ "ซูซูกิ อากิระ" / "รุ่นพี่อากิระ" / มหาลัยชินชูที่นากาโน่ / อายุช่วง 21 / เรื่องผี ม.ปลายบนเขานากาโน่ / แผนที่จากหอสมุด
- หน้าที่ในโครงเรื่อง: (1) อธิบายว่ากลุ่มรู้ทางขึ้นเขาได้ยังไง (2) เพิ่มน้ำหนักให้ข่าวลือเจ้าสาว (ถ้าเรื่องผีบนเขา "มีคนเจอมาก่อน" ข่าวลือก็ไม่ใช่แค่ผีเสื้อ) (3) วาง easter egg ที่ Epilogue (คอมเมนต์แก้ไขประวัติศาสตร์ทางเดินป่าปี 1991) จะมาเก็บ

## 6. เส้นห้ามของ Arc 1

### 6.1 เรื่องตัวร้าย — ห้ามเฉลย / ห้ามส่งสัญญาณแรงเกิน

- ชิองใน Arc 1 คือ "คนช่วยงานที่รู้มากกว่าที่พูด" เท่านั้น — **ห้าม POV ชิอง ห้ามแสดงความคิดเขา ห้ามให้เขากระทำอะไรที่เฉลยว่าเขาคือฆาตกร** (เงาชุดขาวของริสะต้องกำกวม — มองไม่ชัด อาจเป็นผ้าที่ตาก เป็นริมฝีปากหมอก)
- ความผิดปกติของชิองที่ให้ได้ คือแค่ระดับ "ผู้อ่านย้อนกลับมาอ่านแล้วเสียว": จำชื่อเก่ง / รู้ทางเขาละเอียด / เงียบเวลาคนพูดถึงข่าวลือ (antagonist_design ระบุพฤติกรรมนี้ไว้) / ไม่อยู่ในรูปถ่าย — เลือกใช้โดยไม่รวมทุกอย่างในฉากเดียว
- ห้ามเรียวยะสรุปถึงตัวชิองใน Arc 1 — สูงสุดคือบท 4 ท้ายบท: "นี่ไม่ใช่บ้านผี — มีคนอยู่เบื้องหลัง" (outline seed 4.3) โดยไม่ระบุตัว

### 6.2 ประโยคลายเซ็นของชิอง — ใช้ไม่ได้ทั้งหมดใน Arc 1 (ตาม voice_principles + shion_madoka)

- ❌ "บ้านหลังนี้ไม่ฆ่าใคร มันแค่ปิดประตู แล้วฟังว่าพวกคุณเรียกชื่อใครก่อน" — เก็บไว้ใช้ครั้งแรกเมื่อชิองยังสวมหน้ากากใน Arc 2-3
- ❌ "ก่อนตาย ตอบให้ตรงสักครั้งได้ไหม?" / "ทำไมพวกแกถึงกลับไปช่วยกันได้" / "คนเรา…เปลี่ยนได้ไหม?" / "อย่าพูดเหมือนแกรู้จักเธอ" — ทั้งหมดสงวนไว้ตามจังหวะที่กำหนดใน shion_madoka.md (บท 11-12)
- ❌ "คนเราไม่ได้มีแค่วินาทีที่แย่ที่สุดของตัวเอง" — ห้ามทุกตัวละคร ทุกบท (ของอายาเมะ ใช้เฉพาะ Extra Arc E01)

### 7.3 ใครรู้อะไรตอนไหน (สถานะความรู้ — ปิดท้ายแต่ละบท)

**จบบท 1:**
- ทุกคน: มีบ้านชื่อ "คุซาบิ" บนเขาคุโระมิโซะ + มีเรื่องเล่าเกี่ยวกับมัน (จากปากชิอันพอเป็นพิมพ์แรก) + ชิองจำชื่อทุกคนได้
- ริสะ (คนเดียว): รู้สึกว่าชิองพูดถึงบ้าน "เหมือนพูดถึงคนที่ยังมีชีวิต" (outline 1.2) — ยังไม่บอกใคร
- เรียวยะ (คนเดียว): ได้ยินเสียงผู้หญิงร้องไกล ๆ + จดกลิ่นจาง ๆ จากชิอง — ไม่เชื่อมกับอะไร

**จบบท 2:**
- ทุกคน: ข่าวลือ 5 เวอร์ชัน + เจ้าของเรียวกังบอก "อย่าขึ้นไปเลยครับ" ด้วยเสียงไม่มั่น + เรื่องรุ่นพี่อากิระของนาโอะ + มีแผนที่เก่าอยู่ในมือนาโอะ
- ริสะ: เห็นเงาชุดขาว — บอกมิซากิแบบถามแล้วเก็บเอง — มิซากิรู้ว่าริสะ "เห็นอะไรบางอย่าง" แต่ไม่รู้ว่าอะไร
- เรียวยะ: สังเกตว่าชิองรู้มากกว่าที่พูด + เสียงร้องเมื่อคืนไม่ต่อเนื่อง — ยังเป็น "ข้อมูลลอย" ทั้งหมด

**จบบท 3:**
- ทุกคน: ของริสะถูงคนย้ายไปวางแน่ (ไม่ใช่หายเอง) + ป้ายทางขึ้นถูกขูดให้อ่านไม่ออกโดยเจตนา + ทางขึ้นลื่นเสี่ยง + ไม่มีสัญญาณ
- เรียวยะ: เห็น "จังหวะการหายผิดธรรมชาติ" (outline 3.2) — พูดให้กลุ่มฟังระดับหนึ่ง แต่ไม่มีใครสน และเขายังไม่ดันต่อ (เพิ่งพอ ไม่พอสรุป)
- ริสะ: รู้สึกผิดว่าทำให้ทุกคนต้องขึ้นเขาเพราะของตัวเอง

**จบบท 4:**
- ทุกคน: บ้านนี้เคยมีคนตาย (รอยเลือดเก่า รอยเล็บ) + มีคนใช้บ้านเมื่อเร็ว ๆ นี้ (ร่องรอยใหม่บนฝุ่น) + เสียงกระดิ่งไม่มีลม + **ประตูปิดจากด้านนอก = มีคนทำ = ไม่ใช่ผี** — กลัวจริงแต่ยังไม่พัง
- เรียวยะ: จำ "ลายพื้นรองเท้าแปลก ๆ บนโคลน" ไว้ (ยังไม่เชื่อมกับรองเท้าทำงานคู่หนึ่งที่เคยเห็นที่เรียวกัง) — นี่คือหลักฐานที่เขา "มีแต่ไม่กล้าพูด" ตาม breaking point ของเขาในบท 11
- ริสะ: เห็นอะไรผ่านหน้าต่างชั้นสองแต่ประโยคถูกประตูปิดกลืน — ความลับเล็ก ๆ ของเธอชิ้นที่สอง
- ชิอง: (นอกจอ) รู้ทุกอย่าง — ผู้อ่านไม่ควรรู้อะไรเกินกลุ่มตัวเอกเลย

### 7.4 หมุดเล็กที่ห้ามสะดุด

- รถที่มา: มาด้วยรถโดยสาร/รถเช่าจากตัวเมือง 2-3 ชม. — รถจอดที่หมู่บ้าน ไม่ได้ขึ้นไปถึงเชิงเขา (ทางเดินขึ้นเริ่มจากจุดเดิน 15 นาทีจากหมู่บ้าน ตาม setting_bible)
- เวลาเดินขึ้นเขา 45 นาที-1 ชม. — ออกเดินบ่าย ~2 โมงครึ่ง-3 โมง ถึงบ้านใกล้ 4 โมง — ประตูปิดช่วงแสงเริ่มหมด (~5 โมงครึ่ง-6 โมง ปลายร้อน) — ตรวจให้บท 4 อ้างเวลาแสงสม่ำเสมอ ไม่ใช่ความมืดสนิท
- จำนวนคนที่รู้เรื่องเงาชุดขาว: ริสะ (เห็น) + มิซากิ (รู้ว่าริสะเห็นอะไร) — ไคโตะกับเรียวยะกับนาโอะไม่รู้จนกว่าริสะจะบอกเอง (Arc 2)
- กล้องนาโอะ: ยังไม่มีใครเคยดูคลิปย้อนหลัง — คลิปทุกม้วนยังอยู่ครบถ้วนจนถึง Arc 3
- เรียวกังมีแขกกลุ่มอื่นไหม: ไม่มี — โลว์ซีซั่น มีแขกอีกคู่เดียว (คนแก่ ไม่ปรากฏตัว) เพื่อให้เรียวกังเปลี่ยวแต่ไม่ร้างผิดจริง (setting: มีแขกน้อย ไม่ใช่ไม่มีเลย)
