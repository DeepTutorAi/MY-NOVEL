## 1️⃣ ปัญหาที่วินิจฉัย (จาก draft จริง)

อ่าน `chapter_03.md` ครบทั้งไฟล์แล้ว ปัญหาไม่ใช่ตัวละครไม่ดี — เสียง Ilyra ชัด และ Maera "สาวเท่" ตรงโจทย์อยู่แล้ว แต่โครงสร้างอารมณ์ของคู่นี้ทั้งเรื่องเอนไปทางเดียว:

1. **Ilyra = มาสก์ตลก 100%** — ทุก (หัว) เราะในบท 3 คือการ "กลบ" อะไรบางอย่าง (กลบวิตก / กลบความเงียบ / กลบควรหน้าตาเมื่อ Cael พูดเรื่องน้องชาย) ตามบันได "หัวเราะไม่งั้นความเงียบกลืนกิน" ของ Henrick ซึ่งถูกต้องตาม wound แต่ถ้าเป็นแค่นี้ตลอด 10+ บท เธอจะกลายเป็น "คนตลกที่เศร้า" ธรรมดา — ผู้อ่านจะไม่เห็นว่า**เธอเคยมีความสุขจริงๆ** อยู่ด้วย
2. **ไม่มีฉากที่ Ilyra "ชนะ" ด้วยความสุขสนุก** — ฉากระวังภัย (โครเว็กซ์) ฉากซ่อมเรือ จบลงด้วยการรอด/เอาตัวรอด ไม่ใช่ความสำเร็จที่สนุก
3. **โลกส่วนตัว Ilyra = ศูนย์** — ทรัพย์สินส่วนตัวของเธอในเอกสารคือสิ่งของรักษาชีวิต (แผนที่ เข็มทิศ สมุดบันทึกคนตาย) เธอไม่มีของสะสม ไม่มีงานอดิเรก ไม่มีอะไรที่ "ไม่จำเป็นต่อการเอาตัวรอดแต่เธอเก็บไว้เพราะชอบ"
4. **Ilyra×Maera ในเอกสาร = 3 บรรทัด** — `relationship_map.md` 2.3 มีแค่ initial/turning/final แบบสั้นๆ ทั้งที่เป็นคู่ที่อยู่ด้วยกันบนเรือเดียวกันตั้งแต่ก่อนเรื่องเริ่ม! ผู้อ่านเห็น "ผลลัพธ์" (ทะเลาะกันเป็นนิจ) แต่ไม่เคยเห็น "เหตุ" — ทำไมคนกลัวผูกพันธ์อย่าง Ilyra ถึงปล่อยให้ Maera อยู่บนเรือหลายปี
5. **Maera รับบท "ตัวประกอบขำ" ในฉากคู่กับ Ilyra** — บท 3 เธอเป็นม้าตัวเอกใน dynamic ขนมปัง-หิน แต่ไม่มีฉากไหนที่ **Maera เริ่มเอง** — ทุก action ของเธอเป็นปฏิกิริยา (ถูกถาม ถูกสั่ง ถูกกวน) สาวเท่ตัวจริงต้องมี initiative ของตัวเอง

> **หลักออกแบบ**: พลังบวกของ Ilyra ต้องไม่ใช่ "เปลี่ยนนิสัย" แต่คือการเผยชั้นที่ซ่อนอยู่ — เธอไม่ได้หัวเราะเพื่อปิดบังเท่านั้น เธอหัวเราะเพราะ**เธอเห็นความสนุกในโลกที่คนอื่นเห็นแต่ความสยอง** และความสนุกนี้ต้องมีราคา เพื่อไม่ให้กลายเป็นความเบาหวิวไร้น้ำหนัก

## 2️⃣ Ilyra: ยกระดับจาก "มาสก์ตลก" → "นักสำรวจผู้สนุกจริง"

## 3️⃣ Maera: จาก "ปฏิกิริยา" → "สาวเท่ผู้มี initiative"

### แกนเสริม: The Quiet Initiator (คนเริ่มเองแบบเงียบๆ)

สาวเท่ตัวจริงไม่รอให้ถูกกวน — เธอมีระบบของตัวเองที่ทำงานอยู่เบื้องหลังและค่อยๆ ผลักทุกคนไปข้างหน้าโดยที่ไม่มีใครสังเกต

<AI>
### 1) "The Fix-List" (ลิสต์แก้)
ลิสต์สิ่งที่เธอเคยซ่อม (มีใน `cast_biography.md` แล้ว — เติมส่วนที่ยังไม่มี): นอกจากลิสต์ "ซ่อมสำเร็จ" ที่ยาว เธอ**ไม่มีลิสต์ของสิ่งที่ล้มเหลว** — เพราะไม่ยอมรับความล้มเหลว เราเติม: ด้านหลังสมุดลิสต์ของเธอ มีรายการที่ถูกขีดฆ่าไว้เกือบหมด แต่มีหนึ่งบรรทัดที่เขียนไว้แล้วไม่เคยขีดฆ่า ไม่เคยทำ: **"ซ่อมกล่องดนตรี"** — ไม่ใช่เพราะทำไม่ได้ แต่เพราะถ้าซ่อมเสร็จ มันจะไม่ใช่เครื่องมือ "ไว้ใช้หลอมทองเหลือง" อีกต่อไป — มันจะกลายเป็นของ "ฟังเล่น" อย่างเดียว และ Maera ยังไม่ยอมรับว่าตัวเองเป็นคนที่มีของฟังเล่น
- **ทำไมสนุก**: เป็น "มิติส่วนตัว" ของ Maera ที่โต้ตอบกับสมุดชัยชนะของ Ilyra — สองสมุด สองคน คือชุดของสะสมจิตวิทยาคู่กัน (Ilyra: บันทึกอดีตที่อ่านได้ / Maera: บันทึกอนาคตที่ถูกเลื่อนออกไปเรื่อยๆ)
- **จุดวาง**: เตือนใน Ch 3 ที่กล่องดนตรีปรากฏ (บรรทัดสุดท้ายที่เธอพึมพำว่าอาจต้องหลอมมัน — เพิ่ม: แล้วนิ้วหยุดบนลาน ไม่หมุนต่อ) / payoff ใน Ch 23 ที่แผนบทล็อกไว้ว่า Maera POV มีดของ Tovin — ต่อยอดให้เป็น "รายการที่ตัดสินใจไม่ขีดฆ่าอีกต่อไป" (เธอซ่อมกล่องดนตรีในคืนก่อนภารกิจสังหรณ์ใจ แทนที่จะรออนาคต)

### 2) "ระบบจัดอันดับความโง่ของลูกเรือ" (มุมตลก)
Maera จัดอันดับทุกคนบนเรือตาม "ค่าความเสียหายต่อชั่วโมง" (damage-per-hour — เธอออกแบบหน่วยวัดเอง เรียกย่อว่า DPH ต่อคน): Tovin ทำลาย/สร้างความเสียหายสูงสุดเป็นประวัติการณ์ ตามด้วย Ilyra ที่ทำให้เชือกสึกเร็วกว่ากำหนด ตามด้วย Cael ที่ "ยังวัดไม่ได้ — ไม่แน่ใจว่าเป็นคนหรือเครื่องวัดความชื้น"
- **ทำไมสนุก**: ให้ Maera มีบท "เริ่มเอง" — การจัดอันดับคนอื่นโดยที่ไม่มีใครขอ เป็นความซนแบบ ISTP แท้ (ทำระบบให้ครบจากสิ่งที่ตัวเองสนใจ ไม่ใช่เพราะแคร์คน) — และค่า DPH ของ Cael "วัดไม่ได้" คือเครื่องมือเผยว่าเธอคิดถึงคนใหม่นี้มากกว่าที่ยอมรับ

## 6️⃣ สรุปสั้น (Elevator)

**Ilyra** เดิม = ตลกกลบแผล → เพิ่มเป็น **นักสำรวจที่สนุกจริง**: มีสมุดชัยชนะเล็กๆ (จับต้องได้) · กติกาลับของเรือร่วมกับ Maera · ตัดผมให้ลูกเรือ (ความสัมพันธ์ผ่านมือ) · ความเชื่อ "ทะเลฟ้าเห็นเราหรือเปล่า" พลังบวกมีราคา และยิ่ง arc ไป มาสก์เจือจางตาม speech evolution

**Maera** เดิม = ปฏิกิริยาปากแข็ง → เพิ่มเป็นสาวเท่ผู้มี initiative แบบเงียบๆ: จัดอันดับ DPH ทุกคน (ความซนแบบ ISTP) · บรรทัด "ซ่อมกล่องดนตรี" ที่ไม่เคยขีดฆ่า (มิติส่วนตัวที่โต้ตอบกับสมุด Ilyra) · อารมณ์ของโลหะ · ความเกลียดความเงียบที่ย้อนกลับถึงโรงงานเด็กกำพร้า

**คู่นี้** = สองสมุดสองคน (จับต้องได้ทั้งคู่) + กติกาลับร่วม + สูตรทะเลาะ 4 แบบ — ความต่าง ENFP×ISTP กลายเป็นเครื่องมือสร้างความสนุกใน POV นางเอก โดยไม่แตะ beats ที่ locked ทั้ง 35 บท
