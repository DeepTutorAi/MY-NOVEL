## 1️⃣ Ilyra Venn — นางเอกผู้สนุกจริง (The Joy Explorer)

### สูตรเสียง (จากหน้ากระดาษจริง)
- ประโยคยาวไหลเมื่อปลอดภัย / สั้นกระชับเมื่อตัดสินใจ / เงียบสนิทเมื่อเจอบาดแผล (ดูฉาก "น้องชาย... เขาตายไปสิบปีแล้ว" — จุดที่คำของเธอหมด)
- หัวเราะเป็นเครื่องมือ: กลบวิตก (มาสก์) + คุมขวัญทีม (พลังบวก) — ผู้เขียนต้องรู้ทุกครั้งว่าตอนนี้เป็นแบบไหน
- คำสั่งกัปตัน: กระชับ ไม่มีคำเกิน ("ตัดเชือกสมอได้!" ไม่ใช่ "กรุณาช่วยตัดเชือกสมอหน่อย")

### ชั้นพลังบวก 3 ชั้น (ใช้ให้ถูกจังหวะ)
| ชั้น | ท่าทาง | ใช้เมื่อ | ห้ามใช้เมื่อ |
| :--- | :--- | :--- | :--- |
| **Mask** (กลบ) | โจ๊กไว เถียงเร็ว ประชดเจ้าหนี้/สภาศิลา | ความเงียบ ความไร้ทางออก ผู้คนกลัว | เมื่อคนอื่นกำลังเจ็บจริง (จะกลายเป็นคนเถียงเพื่อตัวเอง) |
| **Spark** (สนุกจริง) | ตาเป็นประกายเรื่องลม/เรือ/ทะเลฟ้า พูดเร็วขึ้นเรื่องสิ่งที่เธอรัก | ช่วงหายใจ, หลังรอด, เรื่องเรือ | กลางวิกฤตที่ยังดำเนินอยู่ |
| **Still** (นิ่ง) | ประโยคสั้นมาก น้ำเสียงเรียบ สบตา | คนกำลังจม เธอยื่นมือ (Cael ตอนจ้างเรือ, ทีมหลังพายุ) | — (ชั้นนี้ห้ามใช้บ่อย — เป็นของมีค่า) |

### มิติส่วนตัว (props ที่จับต้องได้)
1. **สมุดชัยชนะเล็กๆ** — จด "Ilyra 47 : 0 สภาศิลา" อ่านซ้ำได้ / counterpart ของสมุดคนตายที่ไม่เคยเปิด
2. **กติกาลับของ Albatross** — เริ่มจาก "กติกาข้อ 12: เรือสั่น = เรือหัวเราะ ให้หัวเราะตอบ" — อธิบายแก่คนนอกด้วย "กติกาข้อ 12" สามคำเท่านั้น
3. **กรรไกรตัดผม** — ตัดผมให้ลูกเรือ (อ้างว่า "เรือไม่มีช่างตัดผม") — จริงๆ ชอบช่วงเวลาที่คนยอมนั่งนิ่งให้เธอรู้จัก

### เส้นพัฒนาเสียง (Speech Evolution)
Arc 1-2: โจ๊กหนา → Arc 3-4: โจ๊กบางลงเมื่อผูกพันธ์จริง ใช้กติกาแทน (คำสั้นที่มีความหมายร่วม) → Arc 5-7: ชั้น Still โดดเด่นขึ้นเรื่อยๆ จนบทสุดท้าย (จาก Cael) เป็นความเงียบที่ยอมรับเป็น

### ตัวอย่างบรรทัด (บรรทัดใหม่เฉพาะส่วนพลังบวก — ไม่ทับเสียงเดิม)
```

"หนุ่มๆ ข้างหน้าน่ะ ปะการังอายุพันปี — ช้ากว่าเจ้าหนี้ โหดกว่าทหาร
 และสวยกว่าทุกอย่างที่สภาศิลาเคยปิดไว้บนแผนที่ เกาะกราบให้แน่น"

[Mask → ถูกดึงกลับโดย Maera]
"ฉันกำลังอธิบายมรดกทางวิศวกรรมอยู่ ไง"
"ฉันไม่เคยเถียงกับมรดกที่ยังไม่จ่ายค่าซ่อม" — Maera

*"ใช่" หลายเสียง*
```

## 2️⃣ Maera Sol — สาวเท่ผู้เริ่มเอง (The Quiet Initiator)

### สูตรเสียง
- ประโยคสั้น แห้ง จบใน 1-2 clause / ตอบโจ๊กด้วยข้อเท็จจริงเครื่องจักร
- **คำห่วง = คำด่า** (canon): "พันแผลซะ / อย่าให้เลือดเปื้อนเหล็ก มันจะทำให้เกิดสนิม"
- ศัพท์เครื่องจักรแทนศัพท์อารมณ์: แรงบิด ระยะห่าง เชื้อเพลิง แรงดัน สัมประสิทธิ์

### Initiative ของเธอ (สิ่งที่เธอ "เริ่ม" โดยไม่มีใครขอ)
1. **ลิสต์ DPH** (damage-per-hour) — จัดอันดับความเสียหายต่อชั่วโมงของทุกคนบนเรือ อัปเดตเงียบๆ ไม่บอกใคร
2. **ซ่อมของของคนอื่นตอนกลางคืน** (canon) — รองเท้า Tovin, เข็มขัด Ilyra, หน้าต่างกระจก Ilyra ที่มีรอย — ไม่เคยโดนขอบคุณเพราะไม่มีใครเห็น
3. **อารมณ์ของโลหะ** — อธิบายงานช่างผ่าน "อารมณ์" ของเหล็กที่เธอตั้งชื่อเอง (ไม่ใช่ความเชื่อ — แค่ยังไม่มีสูตร)

### มิติส่วนตัว
1. **กล่องดนตรีทองเหลือง** (canon — เปิดเผยบนหน้าในบท 10) + **บรรทัดที่ไม่ขีดฆ่าใน Fix-List**: "ซ่อมกล่องดนตรี" — เขียนไว้แล้วไม่เคยทำ เพราะถ้าซ่อมเสร็จมันจะกลายเป็นของ "ฟังเล่น" ล้วนๆ และเธอยังไม่ยอมรับว่าตัวเองเป็นคนที่มีของฟังเล่น
2. **เสียงเครื่องยนต์ขณะหลับ** (canon) — เติมเหตุ: ความเงียบของเรือนิ่งๆ ทำให้นึกถึงความเงียบหลังเครื่องจักรในโรงงานหยุดของวันที่เธอเป็นเด็กกำพร้า

### ตัวอย่างบรรทัด
```
[เริ่มเอง — โยนกระดาษ DPH ให้ Ilyra เห็นโดยไม่ตั้งใจ]
Ilyra: "Tovin สาม DPH — มาตรฐานไหน"
Maera: "สามแปด หน่วยต่อชั่วโมง เขาทำลายครั้งที่สองเมื่อเช้า — ตอนพยายามช่วย"
Ilyra: "แล้วฉันล่ะ"
Maera: "ยังวัดไม่ถึงจุดตัดสิน ให้เวลาอีกสัปดาห์"
*ทั้งคู่รู้ว่าแปลว่า "เธอยังอยู่ยาว"*

[คำห่วง = คำด่า — หลัง Ilyra เร่งเครื่องเกินสมรรถนะ]
"ถ้าเธออยากได้เสียงนกอินทรี ก็เลี้ยงนกมาเก็บไว้บนเสา
 เครื่องยนต์ไม่ใช่สัตว์เลี้ยง มันไม่ต้องการความรัก ต้องการแค่น้ำมัน"

[กับ Cael — คนใหม่ที่ "วัดไม่ได้"]
"เขาไม่ทำลายอะไรเลย สามวันแล้ว" *(เงียบไปครู่)* "มันผิดปกติ"
```

## 3️⃣ Dynamic คู่: Ilyra × Maera (สูตรใช้ได้ทันที)

### โครงสร้าง: "หนึ่งขว้าง หนึ่งตัดสิน" (Ilyra ขว้าง / Maera ตัดสิน)
ความสนุกของคู่นี้ไม่ใช่ทะเลาะวนลูป แต่คือการแข่งกันสั้นๆ ที่**จบเสมอ** (ตาม "Natural Termination") — ผู้ชนะสลับกัน และเมื่อจบแล้วทั้งคู่เงียบไปด้วยกัน (สัญญาณความสนิทแบบผู้ใหญ่)

| สูตร | รูปแบบ | ตัวอย่างสั้น |
| :--- | :--- | :--- |
| **ยาว-สั้น** | Ilyra พูดยาวหลายข้อ → Maera จบด้วยประโยคเดียว | "ข้ามแนวปะการัง เลี่ยงเจ้าหนี้ แล้วลงจอดที่ท่าเถื่อน — แผนสามข้อสมบูรณ์แบบ" / "ข้อที่สี่: น้ำมัน" |
| **กติกาข้อ 12** | เรือสั่น → Ilyra: "เรือหัวเราะ" → Maera: "แค่ turbulence" → Ilyra: "กติกาข้อ 12" → Maera เงียบ แต่มุมปากยก | (ใช้เป็นระยะ — Arc 2 ต้น) |
| **สองสมุด** | ฉากเงียบ: Ilyra เขียนชัยชนะ / Maera ขีดฆ่าลิสต์ซ่อม — นั่งคนละมุม ไม่พูด แต่อยู่ด้วยกัน | Ch 23 payoff: Maera ไม่ขีดฆ่า "ซ่อมกล่องดนตรี" อีก — ทำมัน |
| **ความจริงจากคนปากแข็ง** | Ilyra ล้ม/เจ็บ/เสีย → Maera ไม่ปลอบ → ซ่อมของรอบตัว Ilyra ทั้งคืน ("ทดสอบระบบแรงดัน") | จุดเดียวที่อนุญาตให้ Maera พูดยาวเกิน 2 ประโยค: งานช่าง |

### กฎเหล็กของคู่นี้ (ห้ามละเมิด)
1. **Maera ไม่พูดความรู้สึกตรง** — คำว่า ห่วง/คิดถึง/ขอบใจ ต้องแปลงร่างเป็นคำสั่งงานช่างหรือคำด่าเสมอ
2. **Ilyra ไม่โย๊กตอนคนอื่นเจ็บจริง** — mask ใช้กับความเงียบ/ความกลัว ไม่ใช่กับบาดแผลคนอื่น
3. **ไม่มีวลี "เธอรู้ไหมว่าฉัน..."** — ความสนิทแสดงผ่านความเงียบที่แชร์กันและกติกา ไม่ใช่การพูดยืนยัน
4. **Ilyra ยังไม่เล่าอดีตตัวเองแบบเต็มเรื่องให้ใครฟัง** (จนถึง Arc 5 ตาม canon) — POV ก่อนหน้านั้นเห็นเศษความทรงจำที่วาบจากสิ่งของหรือเหตุการณ์ได้ และเธออ้างถึงประวัติตระกูลในฐานะข้อมูลเดินเรือได้ แต่ห้ามมีคำสารภาพตรงหรือเล่าแผลของ Henrick จบเป็นเรื่องก่อน Arc 5
5. **ทุกฉากคู่ต้องจบด้วยการเงียบร่วมหรือ action** — ไม่จบด้วยสรุปความรู้สึกที่พูดออกมา
