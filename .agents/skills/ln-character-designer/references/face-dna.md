# Face DNA: preserve identity or design from zero

Read [production-workflow.md](production-workflow.md) for source roles.

## Reference work
Record observed traits; do not redesign them. Eyes/hair need not differ from
another character. Twins, recurring people and a shared drawing convention can
intentionally resemble one another. Do not add a mole, asymmetry or accessory.
Unknown features remain unknown or explicitly proposed.

Separate expression from anatomy: smiling, head turns and lighting can alter
appearance without changing identity. Compare corresponding source features.

## From-zero design
Choose concrete traits serving age, role and the user's aesthetic. Varying eyes,
hair and other axes can address unwanted generic similarity; three axes is an
optional aid, not a threshold. Add quirks only when the brief/design benefits.

| Axis | Record or design |
|---|---|
| Face | Contour, jaw/chin, eye opening/tilt/spacing, lids/lashes, brows |
| Nose / mouth | Structure or ink shorthand, width and resting expression |
| Hair | Silhouette, part/fringe, length, tied sections, texture and palette |
| Marks | Existing detail and anatomical side; having none is valid |
| Age / build | Given age, height/proportions; no invented pixel measurements |
| Outfit / expression | Current task version, distinct from stable identity |

Translate an aesthetic request into visible traits without erasing it. Long
lashes, highlights or jaw shapes are not universal gender restrictions.

## Character Lock
Identity first, then current outfit/expression. Around 40-60 words is useful
when sufficient; preserve necessary detail rather than enforcing a word cap.
Keep identity sentences stable across scenes. A requested wardrobe/expression
change updates the active task version, not approved canon unless asked.
Pass the inspected reference image to the tool when supported, not only text.
