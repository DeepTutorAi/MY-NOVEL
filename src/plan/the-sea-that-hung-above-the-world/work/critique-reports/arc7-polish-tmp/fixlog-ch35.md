## 1. สรุปจุดที่แก้ไขตามข้อตัดสินและรายงานตรวจ

### ก. โครงสร้าง รูปแบบ และมุมมอง (POV)
1. **ป้าย POV หัวบท (ข้อ ก4 / XB-11 / C35-01)**: ปรับเป็น POV คู่ `*POV: เทสสา และ Nio Arvane (ในร่างวาฬ, +300 ปี): พิพิธภัณฑ์ชายฝั่งและอ่าว เมืองท่าที่เติบโตจากหาดเดิม*` เพื่อรองรับทั้งฉากภายในห้องพิพิธภัณฑ์และมุมมองใต้น้ำของ Nio
2. **บรรทัดปิดบทและปิดอาร์ก (ข้อ ก1 / C35-03 / XA-14 / R-09)**: เพิ่มบรรทัด `*จบ อาร์กที่ 7: เมื่อทะเลร่วงหล่น*` ต่อท้าย `*จบ บทที่ 35*`
3. **หัวบท หัวฉาก และรูปแบบ**: คงหัวบท H1 (`# บทที่ 35: พิพิธภัณฑ์ชายฝั่ง`) และหัวฉาก `##` ทั้ง 13 หัวครบถ้วน ปลอด em-dash (`0` ตัว)

### ข. ความต่อเนื่องและแคนอน (Continuity & Canon)
1. **แขนซ้ายและแขนเทียมของ Maera (ข้อ ก2 / R-08)**: เพิ่มข้อความบนป้ายตู้จัดแสดงว่า `*แขนเทียมไม้และเหล็กนี้สร้างขึ้นหลังเรือขึ้นฝั่ง เพื่อแทนแขนซ้ายที่หมดความรู้สึกและต้องตัดออกในภายหลังจากคืนตัดแกนเพลา*`
2. **กติกาเรือข้อเจ็ด (ข้อ ค1 / C35-02 / XA-03 / XB-14)**: เปลี่ยน `*ข้อหก: คนที่ลงจากเรือไปแล้ว ยังนับเป็นลูกเรือ*` และคำอธิบายบนป้ายสมุดกัปตันเป็น `ข้อเจ็ด` ทั้งสองจุด
3. **เข็มทิศทองเหลือง Loran Thorne (ข้อ ค8 / XA-09)**: แก้ป้ายจากสายคล้องขาดทิ้งที่ท่าเรือกระดูก เป็นพกติดตัวลงใต้ในวันที่ออกจากท่าเรือกระดูก ก่อนตระกูลมอบให้หอเก็บรักษา
4. **รูปถ่ายของ Reven (ข้อ ก3 / XA-07 / XA-08)**: แก้รายละเอียดภาพเป็นคนสี่คนยืนหน้าบ้านหลังเตี้ย ๆ กับรั้วไม้ โดยมีเด็กชายวัยหกขวบยืนอยู่ตรงกลาง และแก้ป้ายเป็นเก็บกู้ได้จากซากเสื้อคลุมใกล้ฐานวงเหล็กบนยอดเกาะ
5. **ถุงมือดำของ Kell Marr (ข้อ ค8 / XB-12)**: ปรับป้ายเป็นพบวางอยู่บนขอบวงเหล็กบนยอดเกาะ และระบุว่าเจ้าของถุงมือเป็นทหารกระทรวงที่เดินขึ้นบันไดหอมาส่งคำสั่งและคืนเฉพาะปากกาของ Lienn ในวันสุดท้าย
6. **พังงาเรือ Albatross (ข้อ ค8 / XB-13)**: แก้ตำแหน่งพังงาเหล็กจาก `หัวลำ` เป็น `ท้ายลำ`
7. **อาวุธบนยอดเกาะ (ข้อ ค8 / C35-05 / XA-10)**: แก้ `ทวนเหล็ก` ในย่อหน้าท้ายบทเป็น `ดาบ` ให้ตรงกับตลอดทั้งเรื่อง

### ค. ภาษา รอย AI ความถี่คำ และบทสนทนา
1. **ลดคำว่า "มัน" และห้ามใช้เรียกบุคคล (ข้อ ข1 / C35-04)**: กวาดลด `"มัน"` ในบรรยายจาก 22.08 เหลือ 1.74 ต่อ 500 คำ และเปลี่ยนสรรพนาม `"มัน"` ที่ใช้เรียกบุคคล (Odran, Tovin, Varek, Maera) เป็น `เขา` หรือคำนามเฉพาะทั้งหมด
2. **คำต้องห้าม คำผิด และพิมพ์ตก (ข้อ ข1 / ค8 / C35-06 / C35-07 / C35-10 / C35-11 / R-06 / R-10)**:
   - แก้ `ทว่า` เป็น `แค่`
   - แก้คำพิมพ์ผิด `ของคืน` เป็น `ขอคืน`, `ผนังตะเกียบกัน` เป็น `ผนังขนานกัน`, `โครงตะเกียบ` เป็น `โครงเส้นใย`, `แสงตะเกียบ` เป็น `แสงตะเกียง`, `ครอบวงศ์` เป็น `ครอบครัว`, `ศาลาจารย์` เป็น `เจ้าหน้าที่หอทะเบียน`, `เธอยืนตะเกียงอยู่` เป็น `เธอถือตะเกียงยืนอยู่`, `หญิงชราพูดเธอวางกล่อง` เป็น `"ทุกวันแหละ" หญิงชราพูดพลางวางกล่องกลับลงในตู้`
   - ตัดตัวนับท้ายประโยค (`หนึ่งครั้ง`, `หนึ่งจังหวะ`, `สองจังหวะ`) และตัด `ของฉัน` / `ของเธอ` ที่เกินจำเป็น
   - แก้ย่อหน้าที่มี `ถูก` ซ้ำ 2+ และย่อหน้าที่มีอุปมาซ้อน 2+ (ย่อหน้าท้ายฉากปิดหอ)
3. **กระชับป้ายจัดแสดงและตัดคำคมสรุปธีม (ข้อ ก4 / C35-08 / C35-09 / R-07)**: ตัดโครงสร้างปฏิเสธคู่ขนาน (`ไม่... มันรู้จักแต่...`, `ไม่ใช่ A มันคือ B`) และประโยคสรุปธีมเชิงนามธรรมในบทบรรยายและบทพูดออก
4. **แก้ไขบทสนทนา (D35-01 ถึง D35-17)**:
   - เปลี่ยน `เสียงเด็กสาวตอบ` เป็น action beat ของเทสสา
   - ปรับคำพูดหญิงชราให้เป็นภาษาพูดธรรมชาติ (ตัด `ตอนที่เธอชราแล้ว`, `จนวันตายของเธอ`, `เหลือกำลัง`, `หูซ่าน`, `มือเดียวกับที่ตีของเดิม`, `เท่าตัว`, สำนวนแปล `พูดไว้คำเดียว`, `ฝ่ายที่ต้องถูกรับ`)
   - เติม flow particles และหางเสียง `คะ` ให้เทสสาในจุดที่ห้วน รวมถึงเติม action beat ให้คำถามสั้น (`"ทำไมล่ะคะ" เทสสาเงยหน้าจากตู้ถาม`) และตัดหางเสียงซ้อนใน `"เข้าใจแล้วค่ะ ขอบคุณมากคุณยาย"`

2. `"ถามคนตั้งสิ" หญิงชราพูด`
3. `"รู้สิ" หญิงชราพูด "คนทั้งหอนี้รู้กันหมดนั่นแหละ คนหนึ่งเดินเข้าหมอกไปทางตะวันตก อีกคนเดินลงน้ำมุ่งหน้าไปทางอ่าว"`
4. `"เธอบอกว่ามันอยู่ในน้ำทั้งอ่าวพร้อมกัน"`
5. `"คืนนี้เรือรับส่งไม่วิ่งแล้วนะ" เธอพูด "ฝนกำลังจะลงหนัก ฉันจะกลับทางถนนด้านบน แล้วแม่หนูจะทำอะไรต่อล่ะ"`
6. `"ตะเกียงอยู่ราวด้านทะเล" เธอพูด "ถ้าฝนมันหนักกว่าที่คิด ให้เข้าไปหลบในตัวหอ ประตูหลังฉันไม่ล็อก อย่าไปนั่งข้างราวเหล็กตรงหัวลำตอนฟ้าผ่า"`
7. `"เข้าใจแล้วค่ะ ขอบคุณมากคุณยาย"` (คงความหมายและจังหวะปิดบทสนทนา โดยปรับตัด `นะคะ` ที่ซ้อนกับ `ค่ะ` ตามข้อค้นพบด้านหางเสียงซ้ำ)
