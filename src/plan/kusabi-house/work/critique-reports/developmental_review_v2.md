| **ไคโตะ** | น้องสาวป่วยหนักตอนเขาอายุ 16 — เขาไม่สังเกตเพราะกำลังสอบ | ความล้มเหลว | กลัวการล้มเหลว — ปกป้องจนควบคุม |

3. **ปมต้องเชื่อมกับกับดัก/ปริศนา** — ไม่ใช่แค่ backstory ลอย ๆ
4. **ปมต้องสะท้อนกับแก่นเรื่อง "คนเราเปลี่ยนได้ไหม"** — แต่ในมุมที่ต่างกัน

## 🏗️ กับดัก: ก่อน vs หลัง

### กับดักเดิม (จำเจ)
ทุกกับดักมี pattern เดียวกัน:
1. บีบให้เลือก
2. เห็นร่องรอยเหยื่อเก่า
3. เรียนรู้
4. เรียวยะสังเกต pattern → แก้ปริศนา → เฉลย

### กับดักใหม่ (ต่างกัน)
| กับดัก | ประเภทปริศนา | วิธีแก้ | จุดอ่อนของชิอง |
|---|---|---|---|
| **ห้องเสียง** | ปริศนาทางจิตวิทยา | ฟังและเข้าใจ | ไม่คาดว่าเหยื่อจะ "เข้าใจ" |
| **ประตูสองทาง** | ปริศนาความไว้ใจ | ไม่เลือกคือเลือก | ไม่คาดว่าใครจะ "ไม่เลือก" |
| **ห้องกุญแจ** | ปริศนาความตาย | เข้าใจความผิด | ไม่คาดว่าเหยื่อจะ "เข้าใจ" |
| **ห้องน้ำหนัก** | ปริศนาความอดทน | รอและเชื่อ | ไม่คาดว่าใครจะ "รอ" |
| **Final Gambit** | ปริศนาคำถาม | ถามแทนเลือก | ไม่คาดว่าใครจะ "ถาม" |

### หลักการออกแบบกับดักใหม่
1. **กับดักต่างกัน** — ไม่ใช่ pattern เดียวกันซ้ำ ๆ
2. **วิธีแก้ต่างกัน** — ไม่ใช่เรียวยะสังเกต pattern ทุกครั้ง
3. **กับดักบีบให้ตัวละครเผยตัวตน** — ผ่านวิธีแก้ ไม่ใช่แค่การเลือก
4. **จุดอ่อนของชิอง** — เขาไม่คาดว่ามนุษย์จะ "เข้าใจ/ไม่เลือก/รอ/ถาม" — เพราะเขาเชื่อว่ามนุษย์ทุกคนจะเลือกทันทีเพราะกลัว

## 🎯 ข้อแนะนำสำหรับการเขียน draft

### 1. ใช้ปมใหม่ในการเขียน behavior
- นาโอะ: แสดงว่าเขาเล่นมุกเพราะกลัวความเงียบ — ผ่านการที่เขาพูดตลอดเวลา ไม่ยอมหยุด
- ไคโตะ: แสดงว่าเขาปกป้องเพราะกลัวการล้มเหลว — ผ่านการที่เขาตัดสินใจแทนริสะ
- ริสะ: แสดงว่าเธอยิ้มเพราะกลัวการไม่ถูกต้องการ — ผ่านการที่เธอยิ้มแม้ตอนไม่สบายใจ
- มิซากิ: แสดงว่าเธอควบคุมเพราะกลัวการปล่อย — ผ่านการที่เธอสั่งคนอื่นตลอด

### 2. ใช้กับดักใหม่ในการขับเคลื่อนจิตวิทยา
- ห้องเสียง: บีบให้ตัวละคร "ฟัง" และ "เข้าใจ" — ไม่ใช่แค่แยกเสียง
- ประตูสองทาง: บีบให้ตัวละคร "เลือกไม่เลือก" — ไม่ใช่แค่เลือกทาง
- ห้องกุญแจ: บีบให้ตัวละคร "เข้าใจความผิด" — ไม่ใช่แค่แตะศพ
- ห้องน้ำหนัก: บีบให้ตัวละคร "รอ" — ไม่ใช่แค่เสียสละ
- Final Gambit: บีบให้ตัวละคร "ถาม" — ไม่ใช่แค่ปฏิเสธ

### 3. อย่าอธิบายปมตรง ๆ
ใช้ "show don't tell" — แสดงปมผ่าน behavior ไม่ใช่ exposition

### 4. ใช้ mirror dynamic ระหว่างเรียวยะกับชิอง
ทุกครั้งที่เรียวยะสังเกตบางอย่าง ให้คนอ่านเห็นว่าชิองก็สังเกตเหมือนกัน — แต่ทั้งคู่เลือกทำคนละอย่างกับข้อมูลที่ได้
