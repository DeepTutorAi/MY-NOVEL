# Style selection and default light novel lock

Read [production-workflow.md](production-workflow.md) first. A supplied reference
normally defines visible linework, rendering and palette unless the brief assigns
it another role or asks for a different style. Preserve that style without making
the user request an exception to the default.

## Resolve the active Style Lock

Describe the selected reference's line weight/variation, palette, shadow shapes,
tone/hatching, texture, detail and separation from the background. Capture what is
visible; mark uncertain detail rather than inventing it. For this task, use that
resolved block consistently. Do not force thin uniform ink, flat shading, a halo,
grayscale or non-glossy hair when the selected style intentionally differs.

A layout draft supplies layout; its unrendered marks do not necessarily define
the finish. Preserve its staging and follow the requested cleanup/render stage,
using an approved style source or the default if no other style is specified.

For text-only/from-zero work without a style source, use the default blocks below
verbatim. The default remains identical in both illustration skills.

## DEFAULT STYLE LOCK

```text
Monochrome black-and-white Japanese light novel insert illustration, grayscale only. Clean thin ink lineart with even, crisp line weight, flat cel shading, soft screentone gradients, minimal hatching, hand-drawn look, official light novel interior art. A soft glowing backlight halo behind the character. No color.
```

## DEFAULT AVOID LINE

```text
Avoid: color, 3D render, photorealism, painterly or airbrushed rendering, glossy plastic skin, over-rendered detail, heavy hatching, noisy texture, text, watermark, extra fingers or malformed hands.
```

These negatives describe this default profile. For a selected color, textured,
painterly or other reference profile, write compatible constraints instead.
Never issue both a requested palette and "No color", or reference linework and
a conflicting generic line-weight command.

## Assembly

1. Active Style Lock.
2. Active Character Lock(s).
3. Task pose/expression and framing, or the scene skill's panel/shot structure.
4. Active Background Contract.
5. Short compatible constraints/avoid line.

For ChatGPT image tools, put constraints in the main prompt. State the required
ratio/orientation in words. A clean prompt has one consistent set of instructions.
Avoid substituting generic praise for concrete face/style traits; the user's
aesthetic request still belongs in the brief.
