# Character diagnosis and targeted repair

Use [qc-checklist.md](qc-checklist.md) before quality verdicts. Compare the actual
brief, scoped sources and stage. Fix execution before redesigning the character.

| Issue | First repair | Preserve |
|---|---|---|
| Referenced face changed | Restore visual identity input and remove conflicting age/eye/hair clauses; prefer a local edit | Approved identity |
| Unwanted generic new design | Offer selected trait changes if distinctness is wanted | Intentional resemblance/family relation |
| Reference style changed | Restore observed linework, palette and finish; remove conflicting defaults | Source style |
| Apparent age/build changed | Compare pose/perspective first, then fix demonstrated mismatch | Given age/build; no automatic jaw/body redesign |
| Hand/arm wrong | Correct named chain/wrist/grip without hiding required action | Essential contact and face |
| Outfit changed | Restore current task garment details; remove stale costume clauses | Identity and requested costume changes |
| Expression wrong | Adjust gaze/lids/mouth for this instant | Stable facial anatomy |
| Draft cleanup drifted | Restore geometry; edit only requested region/lines | Pose, camera and untouched regions |
| Background mismatch | Restore requested atmosphere and hierarchy | Required place/story detail |

A user-requested cosmetic edit is authorized work; Minor-only means no
unsolicited automatic regeneration, not refusal to perform that edit.
Use references from the start. Do not change a canonical Lock to fit a failed
output, or wait for two failed text repairs before using the reference.

Write **ยืนยันไม่ได้** for inadequate resolution/occlusion; do not infer hidden
fingers, cup size or exact height from pixels. Ask for a better source only if
it blocks the task. Keep notes in chat or the existing handoff; follow
[production-workflow.md](production-workflow.md) for bounded retries and cleanup.
