# Focused character questions

Inspect the brief and images first. There is no fixed interview sequence.
Ask only missing facts that materially change the requested result, at most
three concise questions per round. Use useful choices/delegation when helpful.

| Situation | Ask only if unresolved |
|---|---|
| Text-only new concept | Age impression, role, face/hair silhouette or outfit |
| Conflicting images | Which supplies identity, style or a single feature? |
| Redesign | What may change and what must stay? |
| Draft continuation | Layout, line cleanup, rendering or final; which region? |
| Unseen detail | Is it needed in this view, or can it remain unknown? |

Known traits need no new questions. A reference can answer face, hair, clothes
and style without requiring a name, numeric height or personality interview.
For delegated choices, state assumptions and produce the proposal.
Preserve user-supplied measurements in the spec, using visual descriptors in
the image prompt where useful. Do not erase an adult build or palette to fit a
template; maintain age-appropriate, non-sexualized school-age designs.
