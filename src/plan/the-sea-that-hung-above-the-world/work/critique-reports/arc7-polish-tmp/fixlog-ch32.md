## 1. สรุปจุดที่แก้ไขตามข้อตัดสินและรายงานตรวจ

### ก. ความต่อเนื่องและแคนอน
- **กติกาเรือข้อเจ็ด (ค1 / C32-01 / XA-01 / XB-03 / R-01)**: เปลี่ยน `"ข้อหก"` เป็น `"ข้อเจ็ด"` ทุกจุดที่อ้างถึงกฎ `"คนที่ลงจากเรือไปแล้ว ยังนับเป็นลูกเรือ"` รวมถึงหัวฉาก `## ข้อเจ็ด` และแก้ `"ใต้ข้อห้า"` เป็น `"ใต้ข้อหก"`
- **จำนวนเรือเก่าจากท่าเรือกระดูก (ก3 / XB-04)**: ปรับช่วงต้นถึงกลางบทจาก 3 ลำ เป็น **2 ลำ** (รวมกับ *Albatross* เป็น 3 ลำ) และให้น้องทั้ง 4 คนของ Pip อยู่บนเรือ **ลำที่สอง** ให้สอดคล้องกับท้ายบทและบทที่ 34-35
- **คำเรียก `"ประตูอภัย"` (ค2 / C32-03 / XA-04 / XB-02 / R-03)**: เปลี่ยนเป็น `"ประตูระบายน้ำ"` ทั้ง 2 จุดในบทบรรยาย
- **แผลเป็นและผ้าพันแผลมือขวาของ Cassian (ค3 / XA-05)**: เติมรายละเอียดผ้าก๊อซที่มือขวาของ Cassian ในจังหวะซุกมือในอกเสื้อ ชักดาบสังหาร Kell Marr ถือดาบ หยิบถุงมือดำวางบนขอบวงเหล็ก และวางมือแตะด้ามดาบก่อนหอถล่ม
- **รอยต่อเวลา `31->32` (ค4 / XB-01)**: ปรับ `"ตั้งแต่เช้า"` / `"ตั้งแต่สาย"` ในช่วงเปิดบท บนยอดหอ และห้องนั่งเล่น ให้สอดคล้องกับการอพยพขึ้นมาจากชั้นล่างหลังประตูระบายน้ำปิดในคืนบท 31 (`เมื่อตอนสาย`, `ตั้งแต่ตอนพาแถวแรกขึ้นมา`, `ตั้งแต่รุ่งสาง`)
- **ตรรกะฟิสิกส์การไม่ข้ามสะพานของ Cassian (C32-02)**: แก้คำพูดที่ขัดกับกลไกเชือก (`ถ้าผมข้ามไป หอคอยจะดึงเรือจมลงไปด้วย`) เป็นเหตุผลเรื่องการอยู่ตรึงทางขึ้นไม่ให้ทหารตามขึ้นมาตัดเชือกก่อนคนสุดท้ายข้าม
- **ตัวสะกดชื่อ `Cassian Veyr` (C32-04)**: แก้ `"ตัว n ท้ายคำ"` เป็น `"ตัว r ท้ายชื่อ"` ให้ตรงกับชื่อเต็ม `Cassian Veyr`

### ข. สรรพนาม ระดับภาษา และบทสนทนา (D32-01 ถึง D32-20, C32-05, C32-06, C32-13)
- **Ilyra เรียก Pip และ Cassian**: เปลี่ยนสรรพนามจาก `แก` เป็น `นาย` เมื่อคุยกับ Pip และเปลี่ยนเป็น `คุณ` พร้อมตัดช่วงถกเรื่องสรรพนามในฉากอำลา Cassian เพื่อคงความขรึม
- **ชั้นเสียง Still ของ Ilyra ในวิกฤต**: ตัดเครื่องหมายอัศเจรีย์ จุดไข่ปลา และคำกำกับ `"เสียงสั่น"` / `"เสียงสั่นเครือ"` ที่ซ้ำซ้อน เปลี่ยนเป็นประโยคสั้นเรียบและ action beat
- **แก้บทสนทนาตาม D32 ครบ 20 ข้อ**: ปรับคำพูด Tovin ให้จับต้องได้ (`หนักเอาเรื่องเลยครับ...`, `ผมไม่ทิ้งมันไว้ข้างหลังหรอกครับ`), รวบคำปลอบเด็กของ Ilyra, เพิ่มน้ำหนักคำสั่งหน้าบันได, ตัด `ค่ะ` ซ้อนของ Sera, ระบุชื่อ `Lienn` แทน `เธอ` ซ้อนในคำพูด Sera, กระชับคำพูด Kell และตัดรูป `"ขอให้คุณ..."`, แก้สำนวนแปลตรง (`count yourself out` และเล่นคำ `ขอ/ถาม`), แก้ลักษณนาม `หอถล่มลงไปตามลำพัง`, ปรับคำพูด Sera เรื่องบันทึกให้สอดคล้องกับคำสั่ง Cassian, ปรับคำถาม Maera และแก้คำขานรับห้วน `"ใต้"` ของ Ilyra เป็นประโยคสมบูรณ์
- **รักษารูปแบบ**: ไม่มี em-dash, คงหัวบท H1, คงจำนวนหัวฉาก `##` ครบถ้วน, คงบรรทัด POV, คงบรรทัดปิดบท `*จบ บทที่ 32*`

### ค. การเกลาสำนวนบรรยายและลดร่องรอย AI
- กระจายโครงสร้างเปิดย่อหน้าด้วยฉาก สภาพแวดล้อม การกระทำ และรายละเอียดทางกายภาพ เพื่อลดสัดส่วนประโยคขึ้นต้นด้วยประธานและแก้ชุดย่อหน้าขึ้นต้นด้วย `เธอ` ซ้ำ 3 ย่อหน้าติด
- ตัดโครงสร้างสรุปความหมายซ้ำซ้อน (`ไม่ได้ A มันมาในรูปของ B` และประโยคอธิบายสิ่งที่ฉากแสดงแล้ว)
- ตัดตัวนับท้ายประโยค (`หนึ่งครั้ง`, `หนึ่งจังหวะ`, `ครั้งเดียว`, `หนึ่งอึดใจ`, `หนึ่งรอบ`), ลดคำว่า `มัน` ในบทบรรยาย, ลดอุปมาและแยกย่อหน้าที่ซ้อนอุปมา 2 จุด รวมถึงแก้ย่อหน้าที่มี `ถูก` ซ้อน 2 ครั้ง

## 3. รายการบทพูดดีที่คงไว้ (จาก `dialogue-ch32.md`)

คงไว้ครบทั้ง 10 บรรทัด โดยปรับเฉพาะจุดที่ต้องตรงกับข้อตัดสินกติกาข้อเจ็ด:

2. `"ไม่ว่าจะเป็นลูกเรือ หรือคนที่คิดว่าตัวเองรู้มากกว่าเชือก"`

4. `"ใบรับนี้ลงไว้ว่าเสียชีวิตแล้วครับ"`
