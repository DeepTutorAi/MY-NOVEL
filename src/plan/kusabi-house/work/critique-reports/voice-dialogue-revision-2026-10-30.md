## ขอบเขตและทิศทาง

ผู้เขียนอนุมัติให้ลงมือแก้เรื่องหลักจากรายงานตรวจวันที่ 29 ตุลาคม และระบุเพิ่มว่าไม่ให้นาโอะใช้ “กู/มึง” เพราะทำให้รู้สึกแยกจากกลุ่ม งานนี้ครอบคลุมบทนำ บท 1–12 และบทส่งท้าย รวมร่างกับฉบับเผยแพร่ที่มีอยู่ ไม่รวม Extra Arc E01–E05

แก้คำพูดตามความต้องการ คนฟัง ความสนิท และแรงกดดันในฉาก ใช้การละสรรพนาม ชื่อ และรูปประโยคที่เหมาะกับสถานการณ์ ไม่แทนคำหยาบด้วยคำประจำตัวชุดใหม่ ไม่ใช้ bio, MBTI หรือรายการคำบังคับเป็นเครื่องตัดสินเสียงพูด รักษาความขัดแย้ง การพูดพลาด ความไม่ให้อภัย และความสุภาพที่มีหน้าที่จริง

คงลำดับเหตุการณ์ เบาะแส กติกาห้อง ความรู้ของตัวละคร ตัวตนที่ยังปิดไว้ และตอนจบ ไม่เพิ่มอดีตหรือ canon เพื่ออธิบายบุคลิก รายงานตรวจเดิมเก็บไว้เป็นหลักฐานก่อนแก้ ไม่มีการเปลี่ยนเนื้อหา

## ผลการแก้

อ่านต้นฉบับเรื่องหลักต่อเนื่องครบทั้ง 14 ส่วนก่อนแก้ โดยแบ่งบท 1–4, 5–8 และ 9–บทส่งท้ายให้ผู้แก้คนละช่วง บทนำตรวจและแก้พร้อมเทียบเทปที่เล่นซ้ำ จากนั้นให้ผู้ที่ไม่ได้เขียนช่วงนั้นตรวจผลต่างและบริบทรอบฉาก การตรวจอิสระ Arc 2 อ่านต้นฉบับใหม่ครบสี่บท ส่วน Arc 1 และ Arc 3 ตรวจผลต่างครบพร้อมบริบทที่เกี่ยวข้อง ไม่อ้างว่าอ่านทุกบรรทัดใหม่ซ้ำทั้งเรื่องในการตรวจอิสระ

ทบทวนข้อเสนอรายบท 39 รายการแล้ว มีการแก้ 38 รายการ และเก็บข้อ 3.3 ซึ่งเป็นมุกแห้งของมิซากิด้วยเหตุผลในตาราง นอกจากรายการเดิมยังแก้สรรพนามนาโอะทุกตำแหน่ง บทพูดริสะที่มีปัญหาลักษณะเดียวกัน และความต่อเนื่องใกล้ข้อความที่แก้

ในต้นทางหลัก 14 ไฟล์ คำ “กู/มึง” จากเดิม 252 ตำแหน่งเหลือ 0 ตำแหน่ง ตัวเลขนี้นับข้อความทั้งชุด ไม่ใช่จำนวนบรรทัดหรือจำนวนบทพูดของนาโอะคนเดียว ตรวจสำเนาเนื้อเรื่องรวม 19 ไฟล์แล้วเป็น 0 เช่นกัน โดยแยกคำว่า “กู้ภัย” ซึ่งต้องคงอยู่

### สิ่งที่เปลี่ยนตามตัวละคร

- **นาโอะ:** ละสรรพนาม เรียกชื่อ หรือใช้คำแทนตัวตามคนฟัง ให้คนอื่นรับความภูมิใจในช่อง ความสงสัย และความกลัวของเขาจริง ความผิดพลาดหน้าห้องน้ำหนักต่อจากการระวังที่ประเมินไม่พอ ไม่ย้อนกลับเป็นคนไม่เคยเรียนรู้ เก็บความโกรธและการไม่ยอมให้อภัยง่ายในบทส่งท้าย
- **ริสะ:** ลดคำเรียกซ้อนและคำสุภาพที่ยืนยันบุคลิกซ้ำ ให้ถามจากข้อมูลที่ฟังมา หยอกเพื่อน ขอให้ผ่อนแรง และยืนยันว่าจะอยู่ด้วยตนเอง ความสุภาพในห้องที่ถูกกักยังมีหน้าที่ต่อรอง ส่วนจังหวะเจ็บหรือคุยกับเพื่อนมีรูปประโยคต่างออกไป เก็บ “ฉันตอบเองค่ะ” เพราะทำให้คนอื่นหยุดตอบแทนจริง
- **ไคโตะ:** ให้ความห่วง การทำแทน และความกลัวว่าจะปล่อยคนอื่นไปปรากฏในบทรับกับการกระทำ การต่อเวลาในบ้านเกิดผ่านการค้านและการยอม ไม่เปลี่ยนเงื่อนไขเงียบ ๆ ช่วงท้ายรับข่าวและขอบเขตของริสะโดยไม่อธิบายพัฒนาการของตนซ้ำ
- **มิซากิ:** มีทั้งการแซว การช่วยดูแลของ การต่อรองเวลา และการยอมรับสิ่งที่ไม่รู้ ลดคำยืนยันว่าทุกอย่างเกี่ยวกับแผน ลดการวินิจฉัยความสัมพันธ์ให้คนอื่นจนจบ เก็บส่วนแก้ปริศนาและการแบ่งทรัพยากรที่มีอยู่แล้ว
- **เรียวยะ:** ระบุสิ่งที่สังเกตได้และส่วนที่ยังไม่แน่ใจ รับคำเตือนของนาโอะไปตรวจจริง ลงมือเมื่อกลุ่มตกลงแล้ว เก็บความกลัวว่าจะกลับมารับเพื่อนไม่ทันโดยไม่แปลงเป็นคำอธิบายธีม
- **ชิองและผู้พูดสมทบ:** ชื่อเรียกกับข้อมูลแขกอ่านต่อเนื่องขึ้น เจ้าของเรียวกังคุยกับแขกด้วยระยะที่ต่อกัน หญิงผ้ากันเปื้อนพูดจากเหตุที่ต้องการปิดข่าวลือ เทปคนที่ 7 ลดการสรุปซ้อน ส่วนการอัดซ้อม ความกำกวมของผู้ให้เสียง ความช่วยเหลือควบคู่กับการกักขัง และความผิดของชิองยังอยู่

- บท 1 คืนภาพเปรียบสมุดกฎหมายให้คำตอบของเรียวยะมีบทส่งรองรับ
- บท 3 เก็บเหตุการณ์ตื่นมาอยู่หน้าห้องน้ำตามต้นฉบับ เรียกที่วางผ้าข้างบ่อตามหน้าที่แทนคำ “ตะเกียบ” ที่ทำให้ภาพผิด รักษาตะเกียบในมื้ออาหาร แก้คำ “สิบโมี” และเรียงเหตุการณ์เวลาเดิม 10:23 ก่อน 10:25 การนับ 10:20 ถึง 10:29 ใช้ไม่ถึงสิบนาที และ summary ฉบับเผยแพร่รับกับเนื้อเรื่อง
- บท 4 ตัดคำบรรยายที่อ้างวลีซึ่งไม่มีในบทพูดใหม่แล้ว และรักษาผู้พูดต่อเนื่องหลังการย้ายบทรับ
- บท 6 ตัดคำตัดสินของผู้บรรยายหลัง “ไว้ค่อยถามก็ได้” ให้การรอคำตอบและเลิกถามทำงาน
- บท 7–8 ระบุการส่งและคืนไฟฉายเดิมทั้งสองดวงก่อนแยกตรวจและขณะช่วยคนเจ็บ ไม่เพิ่มไฟฉายหรืออุปกรณ์ใหม่ ไฟมือถือใช้แบตที่มีอยู่แล้ว
- บท 7 ถอนเฉพาะเวลา 20:51 บนจอซึ่งขัดกับนาฬิกาต้นบท 21:30 เก็บแบต 9% และการมองจอ ไม่เลือกเวลาใหม่โดยไม่มีหลัก
- ไม่ยกตัวจับเวลา 10,000 วินาทีในบท 8 เป็นข้อผิดจากการเทียบชั่วโมงอย่างเดียว: 23:00 บวก 2 ชั่วโมง 46 นาที 40 วินาทีเป็น 01:46:40 ซึ่งยังเข้ากับข้อความท้ายบทว่าเข็มผ่านตีหนึ่งแล้ว จึงคงตัวเลขและกติกาที่มีอยู่

## ผลตรวจและขอบเขตหลักฐาน

| การตรวจ | ผล |
| --- | --- |
| Strict UTF-8 และ U+FFFD ในเนื้อเรื่อง 19 ไฟล์ | อ่านได้ครบ ไม่มีอักขระทดแทน |
| หัวบทและจำนวนเครื่องหมายแบ่งฉากเทียบกับ `HEAD` | ตรงเดิมทั้ง 19 ไฟล์ |

| เทียบ body ร่างกับฉบับเผยแพร่ | ตรงทั้ง 5 คู่ รวมบทนำ |
| ข้อความเทป 11 ที่ซ้ำ | ตรงทั้งบทนำเผยแพร่ ร่างบทนำ และบท 8 |
| Frontmatter | คงเดิม ยกเว้น summary บท 3 ซึ่งแก้ตามเวลาที่อธิบายข้างต้น |

| ตรวจไฟล์ HTML ที่ build ของ Kusabi บท 0–4 | มีข้อความฉบับแก้ครบ และไม่พบสรรพนามต้องห้าม |
| รายงานตรวจเดิม | SHA-256 คงเดิม `C4EEF28BCD86F660AE2960B866634E250E85C76ECAF78A5F6784676943FCD8C6` |
| ขอบเขต Git | เปลี่ยนเฉพาะ 23 ไฟล์เดิมกับบันทึกใหม่หนึ่งไฟล์ ไม่มีการแก้ Extra Arc, bio, เรื่องอื่น หรือโค้ดเว็บ |

Build มีคำเตือน duplicate content ID ของบท Kusabi ทั้งห้า, โฟลเดอร์ `src/content/kusabi/extras` ไม่มีไฟล์ และ Node แจ้ง deprecation ของ `module.register()` งานนี้ไม่ได้แก้ตัวโหลดหรือเพิ่มภาคเสริม ตรวจผลลัพธ์ HTML แล้วใช้ข้อความใหม่จริง จึงรายงาน build ว่าผ่านพร้อมคำเตือน ไม่อ้างว่าไม่มี warning หรือผ่านการตรวจหน้าจอในเบราว์เซอร์

ระหว่างตรวจพบ `git diff --check` ไม่ผ่านเพราะ CRLF ในโน้ตเสียงสามไฟล์ จัดรูปแบบและรันใหม่แล้วผ่าน ปัญหานี้ไม่มีในเนื้อเรื่องทั้ง 19 ไฟล์ คำสั่งอ่านสถิติครั้งแรกเคยผิดไวยากรณ์ PowerShell จากการต่อ pipeline หลัง `foreach` แก้เป็นเก็บผลในตัวแปรก่อนประมวลผล ไม่มีการแก้ต้นฉบับจากคำสั่งนั้น

การตรวจเชิงปริมาณและ build ยืนยันความครบของข้อความ รูปแบบ และผลแปลง Markdown ส่วนความเป็นธรรมชาติและน้ำหนักอารมณ์มาจากการอ่านและการตรวจข้ามผู้แก้ ยังขึ้นกับการอ่านยอมรับของผู้เขียน ไม่ใช่ผลทดสอบที่รับรองรสนิยมโดยอัตโนมัติ
